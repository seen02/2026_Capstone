## 완료 판단과 미검증 범위

계약에 필수 필드·자료형·단위·예제, 세션/이용 상태 전이, 출처·실제/재생 시각·미집계 처리, 모의 공급자→시뮬레이션 공급자 교체 경계를 명시했다. 기존 0–5 프로필과 QR 전체 순위, 대기 입구와 탑승 진입/이용 후 출구, 정적 광장 경로와 실제 보행을 구분했다. 이에 따라 체크리스트의 **공통 데이터 계약 문서 항목만 완료**로 표시한다.

추천 API·세션 발급·임의 좌표 경로 어댑터·동시 수락·이동/대기/운행·보상 저장·영상 분석·휴대폰 접속은 실행하지 않았다. 이번 작업에서 Python/브라우저 회귀 테스트 전체는 재실행하지 않았다. 이 기능들은 후속 구현과 해당 동작 테스트가 필요하다. 현재 서버의 `map_ready`, `runnable: false`, 미구현 상태 API 409는 그대로다.
