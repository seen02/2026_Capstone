# 매직아일랜드 회차·차량 운행 검증

검증일은 2026-11-19다. [체크리스트 5·6번](../implementation-checklist.md#연속-시연-엔진과-지도-개발)을 단일 회차, 차량 운영 순서로 구현하고 서버 경로와 회귀를 검사했다. 시간 수치는 시뮬레이션 내부 초다. [운행 설정과 상태 계약](../../lotteworld/docs/configuration.md#시설별-운행-설정)

## 단일 회차

- 자이로드롭·자이로스윙·자이로스핀·아르카나라이드의 첫 회차는 각각 빈 좌석으로 출발했고 각 장치가 세 회차 이상 반복 운행했다. 가짜 시계로 네 시설 각각 탑승 중 만료된 승객이 하차 경로를 따르고 다리 외부 경계를 지날 때 퇴장으로 집계되는 것을 확인했다.
- 자이로드롭 40명 회차에서 첫 승객과 마지막 승객의 빨간 출구 통과 사이가 39초였다. 하차 배정 25초를 넘겨 마지막 통과까지 승강장을 점유했으며, 다음 회차는 선두부터 받고 승차·확인 시간이 지난 뒤 출발했다.

## 차량·편성 운영

- 초기 1,500명 비교 조건에서 아트란티스 8대가 반복 순환했다. 30초 최소 간격에 도달했고, 코스 구간 4개와 승강장 2곳을 동시에 사용했다. 혜성특급은 하나의 26인승 편성을 재사용했고 230초 최소 간격을 지켰다. 두 시설의 차량·승강장·코스·좌석 상한과 방문객별 차량 배정의 일치를 확인했다.
- 아트란티스의 120초 운행을 60초 구간 두 개로 바꾸자, 승객을 태운 보트가 30초 최소 간격이 지난 뒤에도 첫 구간이 빌 때까지 승강장에서 기다렸다. 첫 구간이 비는 시각에 바로 출발했다. 120초를 일곱 구간으로 나눈 조건에서도 소수 초 경계의 직전·직후에 같은 구간을 두 보트가 점유하는 사례가 없었다.
- 아트란티스 하차를 220초로 늘리고 코스·승차 시간과 최소 간격을 줄여 경합을 만들었다. 승강장 두 곳이 찼을 때 복귀 순서대로 대기했고, 복귀 차량이 다시 하차하고 승강장이 열리자 출발이 재개됐다. 두 보트의 하차가 겹칠 때도 공용 빨간 출구의 최소 통과 간격은 1초였다.
- 초기 1,500명에서 기본 체류 분포로 내부 12시간을 가속 진행했다. 0·0.5·1·6·12시간 표본에서 사람 보존식, 목표 상한, 차량 수·좌석·승강장·코스 점유를 확인했다. 12시간 시점은 누적 진입 8,450명, 현재 체류 1,498명, 누적 퇴장 6,952명이었다. 아트란티스 1,436회, 혜성특급 186회가 출발했다. 장시간 현장 평가와 3D 운행 연동은 체크리스트 후속 단계다.

## 실행한 검사

| 검사 | 결과 |
| --- | --- |
| `python -m unittest discover -s tests -v`와 같은 전체 탐색을 `lotteworld`에서 실행 | 48개 통과. Windows 제한 환경에서는 테스트의 `tempfile.mkdtemp`가 작업 공간 아래에 기본 권한으로 폴더를 생성하도록 실행 세션에서만 대체했다. |
| `node tests/route.test.mjs`, `node tests/navigation.test.mjs` | 2개 통과. 지도 최단 경로·대기줄·광장 경로를 검사했다. |
| `python -m lotteworld_sim.server --validate-only` | 운행 설정과 보행 경로 검증을 통과했다. |
| HTTP 상태 및 설정 재시작 회귀 | `/api/state`에서 여섯 시설이 자동으로 반복 운행한다. 운행 파일 변경은 `/api/meta`에 반영되고 기존 실행은 같은 운행 해시를 유지하며, 새 서버에서 바뀐 차량 수와 해시를 적용한다. |
