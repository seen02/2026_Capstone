# MAREA / 디자인 방향 01

2026-11-11: 이 문서는 아쿠아리움 정적 시안의 디자인 이력이다. 매직아일랜드의 최신 범위·시간·유입·체류는 [개발 명세](../../../docs/design.md)를 따른다. 새 지도는 6개 놀이시설·다리·보행로·대기열의 한눈 구분이 우선이며, 아래 해파리 비주얼·전시 A~F·공연 중심 화면이 새 시뮬레이션의 확정 요구사항은 아니다. 이 시안의 제품 연동은 1차 개발 이후다.

> 현재 화면은 시안 02입니다. 이 문서는 최초 방향을 기록합니다. 최신 간격·타이포·운영자 중립색·760px 모바일/1000px 아이콘 탐색 기준은 [화면 다듬기 기록](unslop-review.md)과 `frontend/shared/styles/`를 기준으로 합니다.

## 컨셉

이름은 조수와 흐름을 뜻하는 MAREA. 관람객에게는 각자의 속도로 만나는 바다, 운영자에게는 공간의 흐름을 읽는 도구로 표현한다. Material 3의 명확한 위계·역할별 색과 Atlassian의 정돈된 작업 공간에서 원칙을 참고하되 특정 화면을 복제하지 않는다. 해당 라이브러리나 공식 컴포넌트를 사용한 구현은 아니다.

## 시각 체계

- 바탕 `#F8F9F5`, 본문 `#142F35`, 주요 동작 `#103E43`, 청록 `#175B59`, 민트 `#E9F3EC`, 라임 `#DCF59E`.
- 여유·보통·혼잡은 녹색·갈색 계열 주황·적색에 각각 문구를 병기한다. 색만으로 상태를 전달하지 않는다.
- 관람객: 큰 제목, 여백, 해파리 SVG, 여유로운 카드, 핵심 동작 한 개. 과도한 그림자와 장식은 줄인다.
- 운영자: 밝은 바탕, 고정된 정보 위계, 작은 반경, 표준화한 수치·단위, 저채도 상태색. 혼잡 구역과 안내판 상태를 우선한다.
- 폰트는 Pretendard 우선 시스템 폴백. 로컬 설치 여부에 따라 달라진다. 브랜드는 시스템 라틴 글꼴, 전시 글자는 일부 Georgia 사용.
- 안내 상태·평면도·공연 이름은 검토용 데이터다. UI의 숫자가 시뮬레이션 결과라는 뜻이 아니다.

## 화면

관람객: 오늘의 관람 → 관람 설정 → 추천 경로 확인 → 경로 선택. 지도에서 전시 상세를 열 수 있고 하단에 여섯 구역 중 상설 전시 5개와 공연 일정이 있다. 선호 선택 후에도 추천 결과는 고정 예시이며 모달에 이를 명시한다.

운영자: 지표 4개 → 혼잡 알림 → 평면도 + 선택 구역 → 인원 추이 + 공연 일정. 지도와 하단 구역 버튼은 같은 선택 상태를 공유한다. 알림 확인은 선택만 바꾸며 알림 자체는 가상 이벤트로 유지한다.

## 반응형·접근성

- 1200px 이하: 간격 축소, 960px 이하: 운영자 메뉴를 아이콘 레일로 전환.
- 700px 이하: 관람객은 한 열과 하단 메뉴, 운영자는 카드 2열·지도·상세 순의 한 열.
- 기본 모달의 키보드 포커스와 Escape 닫기, 버튼 포커스 표시, SVG 구역 Enter/Space 지원, 상태 텍스트, 토스트 라이브 영역.
- 시스템의 모션 감소 설정을 반영한다. 정식 배포 전에는 실제 기기·스크린 리더·대비 검사 등 별도 접근성 검증이 필요하다.

## 평가 후 결정할 것

브랜드명 유지 여부, 관람객 홈에서 큰 비주얼과 지도 중 우선순위, 혼잡 임계값, 관람 선호 단계, 실제 공연 데이터, 현장 위치 인식 방법. 현재 작업은 디자인 시안이며 프로덕션 사양 확정이 아니다.
