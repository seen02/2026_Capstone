1 프로젝트 목표와 범위

1.1 해결하려는 문제

공부나 문서 작업 중에는 한쪽으로 치우친 착석 상태를 오래 유지해도 변화를 알아차리기 어렵다. 단순 주기 알림은 방금 자리를 비웠다 돌아온 경우나 사용자가 작업을 마무리하려는 상황을 충분히 반영하지 못한다. 화면 알림만 제공하면 앱을 보고 있지 않을 때 안내를 놓칠 수 있다.

본 과제는 센서로 관찰 가능한 착석 상태를 기록하고, 사용자가 선택한 기준에 따라 자세 확인과 휴식을 안내한다. ‘작업 흐름 고려’는 집중력이나 작업 종류를 자동 추정한다는 의미가 아니다. 실제 자리 비움의 길이, 누적 착석 시간, 사용자의 알림 미루기 선택을 알림 규칙에 반영한다는 의미다.

1.2 개발 목표

  • 좌판의 좌우 치우침, 등받이 접촉 여부, 착석 여부를 개인별 기준과 비교하여 표시한다.
  • 마지막 유효 휴식 이후 누적 착석 시간과 실제 자리 비움을 반영해 휴식을 안내한다.
  • 앱에서 진동 ON/OFF를 선택하고, OFF 적용 시 진행 중인 진동까지 중단한다.
  • 설정 변경, 알림, 자리 비움, 측정 공백을 기록해 시연 및 비교 실험에 활용한다.

2 시스템 구조와 이용 흐름

2.1 전체 시스템 구조도

그림 1. 센서 수집은 UNO에서, 보정·상태 판정·시간 관리·저장은 노트북에서 수행한다. 스마트폰이 UNO에 직접 연결되는 구조가 아니므로 별도 블루투스 모듈 없이 모바일 화면을 제공할 수 있다. 어댑터와 UNO는 GND만 공통으로 연결하고 두 전원의 +5V는 합치지 않는다.

2.2 이용 흐름

  1. 센서와 진동 모듈을 의자에 고정하고 USB 및 모터 전원을 연결한다.
  2. 노트북 서버를 실행하고 웹앱에서 장치 연결 상태를 확인한다.
  3. 빈 의자, 기준 착석, 좌우 치우침, 등받이 접촉과 비접촉 상태를 등록한다.
  4. 실제 실험용 시간 설정을 확인하고 세션을 시작한다.
  5. 현재 상태, 상대 센서 반응, 휴식 후 누적 착석 시간을 실시간으로 확인한다.
  6. 치우침이 지속되거나 휴식 시점에 도달하면 화면으로 알린다. 진동 ON일 때만 짧은 진동을 추가한다.
  7. 사용자가 알림을 미루거나 충분히 자리를 비우면 해당 규칙에 따라 알림 상태를 갱신한다.
  8. 세션을 종료하고 상태별 시간과 알림 기록을 CSV로 내려받는다.

4 현실적인 수행 가능성

4.1 수행 가능성 판단

특정 의자와 사전 보정한 실험자로 제한하면 학부 과제로 수행 가능한 범위다. 다만 완성된 앱·기록·예외 처리·검증까지 총 몇 시간만으로 끝내기는 어렵다. 가장 큰 불확실성은 센서값 처리 코드보다 부착 위치와 하중 분포, 작은 모터의 진동 전달이다.

위 수치는 실측 생산성이나 완성 보장이 아닌 계획 추정치다. 아두이노와 웹 개발을 모두 처음 접하면 학습 시간이 추가된다. 앞서 논의한 짧은 시연 수준과 본 문서의 검증된 제출 범위를 같은 작업량으로 간주하지 않는다.

4.2 구현 부담을 낮추는 선택

  • UNO의 아날로그 입력 6개로 센서 6개를 직접 읽어 외부 ADC와 채널 확장 회로를 생략한다.[R1]
  • 노트북을 데이터 처리 장치로 사용하여 UNO에 복잡한 모델이나 데이터베이스를 넣지 않는다.
  • 모바일 웹앱을 사용하고 앱스토어 배포·백그라운드 푸시·블루투스 페어링을 필수에서 제외한다.
  • 규칙 기반 분석을 먼저 완성한다. AI 비교가 과목 필수 조건일 때에만 이후 범위에 추가한다.
  • 드라이버가 포함된 진동 모듈을 사용하고, 외장 케이스 가공과 PCB 제작을 하지 않는다.[R3]

4.3 첫 10인시의 실행 여부 판단

첫 10인시 이내에 센서 1개 시험, 좌판 4개 부착, 모터 인지 시험을 우선 수행한다. 착석과 빈 의자를 반복해서 구분할 수 있고, 좌우로 이동할 때 상대값이 반대 방향으로 변하며, 설정한 부착 위치에서 진동을 인지할 수 있어야 다음 단계로 진행한다.

센서가 자주 포화되면 위치·저항값·얇은 덮개를 조정한다. 이는 전기적 포화와 신호 분리 문제를 개선하는 과정이며, 센서 자체의 허용 하중을 늘려 주는 방법은 아니다. 센서를 의자 다리 아래에 놓거나 센서 몇 개로 체중 전체를 받도록 설치하지 않는다.[R2]

두 차례 위치 조정 후에도 좌우 판정이 불안정하면 우선 착석·휴식 코칭을 완성하고 좌우 기능을 제한한다. 진동 전달이 부족하면 두꺼운 좌판 밑에서 등받이의 몸 가까운 위치로 옮긴다. 이때 좌우 피드백의 의미와 실제 인지 여부를 다시 확인한다. 필수 기능을 줄인 경우 변경된 범위와 미달 시험을 문서에 남긴다.

5.2 설치 조건

좌판이 크게 휘지 않고 센서를 고정할 수 있는 의자를 사용한다. 좌우 앞·뒤의 네 지점과 등받이 두 지점을 표시해 매회 같은 위치에 부착한다. 센서와 얇은 덮개는 교체 가능하게 고정하고, 단자·악어클립·모듈 기판은 사용자의 몸이 직접 누르지 않는 곳으로 빼낸다. 연결선을 의자에 고정하여 센서 꼬리 부분에 당김이 전달되지 않게 한다.

SEN0296의 제조사 측정 범위는 20g–10kg로 안내되지만, 이 값만으로 착석 환경의 내구성이나 체중 측정 적합성을 보장할 수 없다. 본 과제에서는 의자 구조가 사람의 무게를 지지하며 센서는 표면의 국소 반응을 읽는다.[R2]

6 실험 및 검증 계획

6.1 상태 판정 검증

보정용 세션과 평가용 세션을 분리한다. 보정 이후 실험자가 일어났다가 다시 앉아 두 번의 평가 세션을 수행한다. 보정 데이터를 평가 정확도 산출에 사용하지 않는다.

  • 평가 세션마다 빈 의자·기준 착석·좌측 치우침·우측 치우침을 각 10회씩, 회당 20초 수행한다. 총 80회다.
  • 각 시험의 처음 5초는 상태 전환 구간으로 분리하고 뒤 15초의 최빈 판정을 시험 결과로 사용한다. 같은 프레임들을 독립 표본처럼 세지 않는다.
  • 착석 여부는 80회 전체로 평가하고, 좌우 상태는 실제 착석한 60회로 평가한다. 등받이 접촉은 별도로 접촉·비접촉 각 10회 시험한다.
  • 목표는 착석 여부 95% 이상, 착석 중 좌우 상태 85% 이상, 등받이 접촉 여부 90% 이상이다. 미판정은 정답으로 제외하지 않고 오류에 포함한다.
  • 10분의 자유 착석에서 짧은 움직임이 불필요한 자세 알림으로 이어지는 횟수를 관찰하고 목표를 2회 이하로 둔다.

이 목표는 특정 실험자의 제한된 환경에 대한 수용 기준이다. 동일인 반복 시험 결과를 일반 사용자에 대한 정확도나 건강 효과로 확대 해석하지 않는다.

6.3 진동과 사용자 제어 검증

화면 안내만 사용하는 조건과 화면·진동을 함께 사용하는 조건을 각 5회 이상 실행해 인지 시간과 방해 정도를 기록할 수 있다. 한 명의 탐색적 결과이므로 효과 입증이나 통계적 일반화를 주장하지 않는다. 해당 비교는 기능 검증이 끝난 뒤 수행한다.

6.4 검증 환경과 기록

A1 과제 목적 및 필요성

A1.1 과제 목적

본 과제의 목적은 의자에 부착한 압력센서를 이용하여 사용자의 착석 상태와 지속 시간을 관찰하고, 실제 자리 비움과 사용자의 선택을 반영한 휴식 안내 시스템을 구현하는 것이다. 사용자는 웹앱에서 현재 착석 상태와 누적 기록을 확인하고, 필요한 경우 화면을 보지 않아도 진동으로 안내를 인지할 수 있다.

진동 피드백에는 ON/OFF 기능을 제공한다. 사용자가 OFF를 선택하면 현재 출력 중인 진동을 포함한 모든 진동을 중단하고, 상태 분석과 기록은 계속 제공한다. 알림 시점을 사용자가 조절할 수 있도록 휴식 안내 미루기 기능을 포함한다.

A1.2 필요성

책상에서 작업하는 사용자는 자신의 착석 상태 변화를 지속적으로 관찰하기 어렵다. 또한 일정 시간이 지날 때마다 발생하는 휴식 알림은 실제 자리 비움이나 사용자의 작업 마무리 시점을 반영하지 못한다. 따라서 착석 상태의 관찰과 알림 제어를 하나의 흐름으로 연결할 필요가 있다.

본 시스템은 ‘센서 측정 → 상태와 시간 판단 → 화면 또는 진동 안내 → 사용자 반응과 자리 비움 확인 → 기록 갱신’의 흐름을 제공한다. 사용자 상태를 일방적으로 교정하기보다 관찰 가능한 정보를 제공하고 알림을 선택할 수 있게 하는 데 중점을 둔다.

A1.3 적용 범위

실험 범위는 센서를 부착한 의자 1개와 사전에 보정한 실험자 1명으로 제한한다. 압력값으로 좌우 치우침과 등받이 접촉, 착석 여부를 구분하며, 정확한 척추 각도·질환·집중도는 판정하지 않는다. 제품 양산과 상용화는 수행 범위에 포함하지 않는다.

그림 A1. 노트북이 의자와 웹앱 사이의 통신 및 분석을 담당한다. 진동 모듈은 별도 5V 전원을 사용하며 UNO의 출력은 제어 신호로 사용한다.

개인 보정은 빈 의자와 기준 착석, 좌우 치우침, 등받이 접촉 여부를 반복 측정하는 방식으로 수행한다. 이를 바탕으로 상태별 경계를 설정하고 짧은 움직임에는 알림을 발생시키지 않는다. 휴식 안내는 마지막 유효 휴식 이후의 누적 착석 시간이 기준에 도달했을 때 제공하며, 짧은 자리 비움은 시간 누적을 멈추고 충분한 자리 비움은 타이머를 초기화한다.

진동 OFF는 명령 전달과 장치 응답을 확인한 뒤 적용 완료로 표시한다. 연결이 끊겨 장치 확인이 불가능할 때는 적용 대기 또는 연결 끊김으로 표시한다. 장치는 서버 생존 신호가 중단되면 진동을 자동 중지하고, 재연결 직후에는 이전 알림을 재생하지 않는다.

A2.3 수행 계획과 실현 가능성

부품 수령 후 4주 동안 하드웨어 시험, 상태 판정과 저장, 앱 및 진동 통합, 비교 실험과 문서화를 순서대로 수행한다. 기본 구현 48–72인시와 예비 12–18인시를 포함하여 총 60–90인시를 계획한다. 첫 주에 센서 상태 분리와 실제 진동 인지가 가능한지 확인하여 범위를 확정한다.

의자를 제외한 예산은 약 23만–28만원이며, 최대 지원금 50만원 범위 안에서 예비 부품과 설치 소모품을 확보한다. 보유 노트북과 스마트폰을 활용하며 PCB 제작·배터리 설계·네이티브 앱 배포를 생략하여 부담을 줄인다.

A3 기대효과 및 활용방안

A3.1 기대효과

사용자가 자신의 착석 패턴과 시간 기록을 확인하고, 실제 자리 비움과 작업 상황에 따라 휴식 안내를 조절할 수 있을 것으로 기대한다. 진동을 선택적으로 사용할 수 있어 앱 화면을 계속 보지 않아도 안내를 받을 수 있다.

효과는 고정 주기 타이머 대비 불필요한 휴식 알림 수, 필요한 알림의 누락 수, 알림 인지 시간, 사용자가 느낀 방해 정도로 평가한다. 자세 교정이나 건강 개선을 이미 달성한 효과로 제시하지 않으며, 실제 측정 결과와 기대를 구분하여 보고한다.

A3.2 활용방안

초기 결과물은 개인 학습 공간과 실습실에서 착석 습관 및 알림 방식의 사용성을 비교하는 교육용 실험 장치로 활용한다. 센서 수집부터 웹앱·시간 규칙·피드백 제어까지 연결되어 임베디드와 소프트웨어 통합 설계 사례로도 사용할 수 있다.

후속 과제로 다른 의자와 실험자에 대한 재현성, 센서 부착 방식의 안정성, 무선 통신, 진동 전달 구조를 검토할 수 있다. 이러한 확장은 본 과제의 필수 완료 조건과 분리하여 추진한다.

C1 서론과 개요

본 문서는 별첨 B의 요구사항을 구현하기 위한 하드웨어 배치, 모듈 책임, 판정 로직, 시간 처리, 통신 규약, 저장 구조, 화면 구성을 정의한다. 준비한 의자 1개와 사전 보정한 실험자에 대한 로컬 실행 시스템을 대상으로 한다.

설계의 핵심은 UNO를 수집·출력 장치로 유지하고, 노트북 서버가 판정과 시간 및 기록의 단일 기준을 갖도록 하는 것이다. 브라우저는 표시와 요청을 담당하며 브라우저마다 별도 휴식 타이머를 운영하지 않는다. 설정값과 목표 성능은 초기 설계값으로, 평가 데이터에 맞추어 사후 조정한 값을 같은 평가 결과로 보고하지 않는다.

C3 하드웨어 및 배선 설계

C3.1 센서와 핀 배치

방향은 의자에 앉은 사람의 좌우를 기준으로 한다. 표의 순서는 통신 프레임·보정 파일·화면에서 동일하게 유지한다.

채널 UNO 핀 설치 위치 데이터 이름
0 A0 좌판 왼쪽 앞 seat_left_front
1 A1 좌판 왼쪽 뒤 seat_left_rear
2 A2 좌판 오른쪽 앞 seat_right_front
3 A3 좌판 오른쪽 뒤 seat_right_rear
4 A4 등받이 왼쪽 back_left
5 A5 등받이 오른쪽 back_right

C3.2 센서 분압 회로

각 채널은 아래와 동일한 회로로 구성한다. 10kΩ은 출발값이며 실제 반응이 포화되거나 변화 폭이 너무 작으면 1kΩ·4.7kΩ·47kΩ을 시험하고 최종값을 보정 파일에 기록한다.

UNO 5V ── 압력센서 FSR ──┬── A0부터 A5 중 해당 입력
                         │
                      저항 10kΩ
                         │
UNO GND ─────────────────┘

출력 전압은 Vout = 5V × Rfixed / (Rfsr + Rfixed)이다. 위 연결에서 힘이 증가하여 센서 저항이 감소하면 ADC 값이 커진다. 센서값은 10비트 ADC 원시값 0–1023으로 전송하며 이를 kg으로 변환하지 않는다. 아날로그 입력의 부유를 막는 저항 연결을 확인한다.

C3.3 전원과 모터 연결

UNO는 노트북 USB로 전원을 공급한다. 모터 모듈 두 개의 VCC는 P9582 어댑터의 5V에 연결하고, 모듈 GND·어댑터 음극·UNO GND를 공통으로 연결한다. D5와 D6은 각각 모듈의 신호 단자로 연결한다. 연결선 색상만 믿지 않고 기판의 VCC·GND·신호 표기를 확인한다.

외부 어댑터의 +5V를 USB 전원이 연결된 UNO의 +5V와 합치지 않는다. 5V 어댑터는 UNO의 배럴잭이 아닌 모터 전원용 단자대에 연결한다. 모터 모듈 전원 근처에는 470µF 전해콘덴서와 100nF 세라믹콘덴서를 병렬로 배치하며, 전해콘덴서의 극성을 확인한다. 브레드보드 전원 레일이 중간에서 나뉘는지는 도통 측정으로 확인한다.

C3.4 부착과 시험 순서

처음부터 의자에 모든 부품을 붙이지 않고 센서 1개 손 누름 시험, 모터 1개 시험, 6채널 시험, 실제 착석 시험 순으로 진행한다. 센서 감지면은 얇은 천으로 덮고, 기판과 단자는 좌판 가장자리 또는 등받이 뒤쪽으로 빼낸다. 모터 부착 위치는 실제 사용자 인지 시험으로 정한다. 장시간 지속 진동 대신 짧은 펄스를 사용한다.

C4 보정과 상태 판정 설계

C4.1 표본 수집과 전처리

펌웨어는 약 100ms마다 6채널을 읽어 10Hz로 전송한다. 분석은 서버에서 수행하며 채널별 최근 5개 유효 프레임의 중앙값을 사용한다. 보정과 평가에서도 같은 필터를 사용한다. 누락 프레임을 복사해서 정상 데이터처럼 채우지 않는다.

빈 의자·기준 착석·좌측 치우침·우측 치우침을 각 20초씩 2회 수집한다. 기준 착석 중 등받이 접촉과 비접촉을 각각 추가 수집한다. 자세 전환 직후 5초는 보정 통계에서 제외한다. 총 보정 과정은 안내와 자세 전환을 포함해 약 5–10분을 예상한다.

C4.2 채널 정규화

각 채널 i에 대해 빈 의자 구간의 중앙값을 b_i로 저장한다. 착석 상태 보정 데이터의 95백분위에서 b_i를 뺀 값을 s_i로 정의한다. s_i가 초기 품질 기준 20 ADC 미만이면 반응 부족 후보로 표시하고 재부착 또는 재보정을 요청한다. 20이라는 값은 실험에서 조정할 수 있는 품질 설정값이다.

x_i = 최근 5개 유효 ADC 값의 중앙값
q_i = max(0, (x_i - b_i) / s_i)
seat_sum = q_0 + q_1 + q_2 + q_3
left_sum = q_0 + q_1
right_sum = q_2 + q_3
left_ratio = left_sum / max(seat_sum, epsilon)
back_sum = q_4 + q_5

epsilon은 0 나누기를 막기 위한 작은 양수다. 분석용 q_i는 1보다 커질 수 있으며 화면 막대만 표시 범위로 제한한다. 좌우 비율은 정규화된 센서 반응의 비율이지 실제 신체 하중의 좌우 비율이 아니다.

C4.3 착석 여부 판정

빈 의자 seat_sum의 95백분위를 E, 실제 착석 보정 seat_sum의 5백분위를 O로 둔다. O가 E보다 충분히 크지 않으면 보정 실패로 처리한다. 충분한 분리는 O - E가 빈 의자 변동 폭의 3배 이상이고 사전 설정한 최소 차이를 넘는지로 확인한다. 최소 차이는 보정 파일에 기록한다.

착석 진입 경계는 E + 0.6 × (O - E), 빈 의자 진입 경계는 E + 0.4 × (O - E)로 정한다. 경계 사이에서는 이전 상태를 유지하는 히스테리시스를 적용한다. 새 상태가 1초 지속되면 확정한다. 1초는 입력 흔들림을 줄이는 설계값이며 수용 시험에서 지연과 함께 확인한다.

C4.4 좌우 치우침 판정

기준 착석 left_ratio의 중앙값을 r0, 좌측 치우침 중앙값을 rL, 우측 치우침 중앙값을 rR로 둔다. rR < r0 < rL의 순서와 상태 구간 분리를 확인한다. 기준 착석의 5–95백분위 구간이 좌우 치우침 구간과 크게 겹치면 임계값을 억지로 만들지 않고 재보정을 요청한다.

좌측 진입 경계는 (r0 + rL) / 2, 우측 진입 경계는 (r0 + rR) / 2로 둔다. 기준 복귀 경계는 각 진입 경계보다 r0 쪽으로 25% 이동시켜 경계 부근의 반복 전환을 줄인다. 후보 상태가 1초 유지되면 현재 상태로 확정하며, 알림을 위한 지속 시간은 확정된 상태에서 별도로 계산한다.

C4.5 등받이 접촉과 품질 상태

back_sum에 대해 접촉·비접촉 보정 분포를 이용하여 착석 판정과 같은 방식의 두 경계를 만든다. 접촉 여부는 좌우 상태와 별도 필드로 저장한다. 빈 의자에서는 좌우와 등받이 상태를 ‘해당 없음’으로 표시한다.

ADC 상단 포화가 5초 이상 지속되거나 값이 장시간 고정되면 센서 이상 후보로 표시한다. 낮은 값이나 고정값만으로 단선 여부를 확정할 수는 없다. 비접촉과 단선이 구분되지 않는 경우 원시값·경고를 보여 주고 운영자가 확인한다. 보정 미완료·데이터 단절·반응 분리 실패는 ‘미판정’으로 표현하며 정상 상태로 집계하지 않는다.

시간 계산에는 서버의 단조 증가 시계를 사용하고, 저장·조회에는 UTC 시각과 한국 시간 표시를 사용한다. 정상 프레임 사이의 실제 시간 차이를 합산하며, 500ms보다 큰 프레임 간격은 상태를 추정해 채우지 않고 공백으로 분리한다. 별도 100ms 감시 작업이 마지막 수신 이후 500ms를 넘으면 현재 상태를 미판정으로 전환하고, 2초 이상 없으면 장치 연결 끊김을 표시한다. 새 프레임이 도착해야만 단절을 발견하는 구조를 피한다.

C5.3 상태 전이와 휴식 인정

그림 C1. Seated는 착석, Away는 아직 유효 휴식에 도달하지 않은 자리 비움, Rested는 유효 휴식을 한 번 인정한 빈 의자, Unknown은 측정 공백이다.

착석에서는 total_seated_s와 seated_since_rest_s를 증가시킨다. 빈 의자에서는 둘 다 증가시키지 않는다. Away에서 설정한 유효 휴식 시간에 도달하면 seated_since_rest_s를 0으로 하고 rest_credited를 참으로 설정하여 초기화 이벤트를 한 번만 기록한다. 짧은 자리 비움 후 복귀하면 기존 누적을 유지한다.

데이터 공백은 Away의 연속성을 끊으며 유효 휴식의 근거로 사용하지 않는다. 공백 전까지의 유효 착석 누적은 보존하되 ‘공백 포함’으로 표시한다. 복구 뒤 빈 의자로 확인되면 그 시점부터 새 자리 비움 시간을 계산한다. 세션 도중 보드만 재연결되면 서버의 누적은 유지하고, 서버 자체가 재시작되면 이전 세션을 중단으로 닫고 새 세션에서 시작한다.

C5.4 알림 조건과 우선순위

자세 안내는 좌우 치우침이 자세 기준 시간 이상 지속되고 같은 방향의 재알림 간격이 지난 경우 발생한다. 등받이 비접촉만으로는 기본 자세 진동을 발생시키지 않는다. 휴식 안내는 착석 중이며 seated_since_rest_s가 기준 이상이고, 미루기와 재알림 제한이 해제된 경우 발생한다.

두 조건이 동시에 성립하면 화면에는 각각의 원인을 표시할 수 있으나 진동은 휴식 패턴을 우선한다. 자세 패턴은 대기열에 쌓지 않고 다음 평가 주기에 현재 상태와 재알림 간격을 다시 확인한다. 자리 비움은 모든 진동을 중단하며, 기준 자세 복귀는 자세 진동만 중단한다. 기준 복귀만으로 휴식 안내가 해제되지는 않는다.

미루기는 휴식 안내가 발생한 뒤 사용할 수 있다. 미루기 선택 시 현재 휴식 진동을 중단하고 snooze_until을 갱신한다. 시간이 만료되면 현재 상태와 누적 시간을 다시 평가한다. 유효 휴식이 먼저 발생하면 미루기와 이전 휴식 안내 상태를 해제한다.

화면 안내 OFF는 팝업·배너 발생만 억제하며 기본 상태 표시와 기록은 유지한다. 진동 설정과 독립적으로 동작한다. 안내 조건 충족, 실제 화면 노출, 진동 요청과 장치 응답은 서로 다른 이벤트로 기록한다.

C6.1 패턴과 출력 한도

1회 명령의 전체 패턴은 2초 이하로 제한한다. 펌웨어는 delay로 대기하지 않고 millis 기반 상태 기계로 제어한다. 신호 처리가 진행되는 동안에도 센서 읽기·OFF·생존 신호 처리가 가능해야 한다. 기판 부팅과 초기화 때 D5·D6을 LOW로 설정한다.

C6.2 진동 ON/OFF 적용 절차

  1. 사용자가 진동 설정을 변경하면 서버에 희망 설정과 설정 버전을 저장한다.
  2. OFF 요청은 새 진동 예약을 즉시 취소하고 우선 전송한다. 보드 응답 전까지 앱에는 ‘OFF 적용 중’을 표시한다.
  3. 보드는 OFF를 받으면 양쪽 출력을 LOW로 만들고 패턴을 지운 뒤 해당 명령 ID의 ACK를 보낸다.
  4. 서버는 현재 연결 세대와 명령 ID가 일치하는 ACK를 확인한 뒤 ‘OFF 적용 완료’로 표시한다.
  5. 응답이 없으면 동일 ID로 제한 재시도한다. 여전히 응답이 없으면 ‘적용 확인 불가’로 표시하고 생존 신호를 중단하여 보드의 타임아웃으로 출력이 끝나게 한다.

OFF 요청을 보드가 받지 못했을 때 1초 이내 정지를 보장한다고 표시하지 않는다. 정상 연결의 정지 목표와 통신 실패 시 보드 타임아웃을 구분하여 시험한다. ON 전환은 이후 새 알림부터 적용하며 이전에 누락한 진동을 재생하지 않는다.

C6.3 생존 신호와 제어권

서버는 500ms 간격으로 생존 신호를 보내며, 보드는 마지막 유효 신호 이후 2초가 지나면 출력을 끄고 진동 허용 상태를 해제한다. 진동 ON에는 유효 연결 세대, 설정 적용, 실행 중 세션, 유효한 데이터와 제어권이 모두 필요하다.

제어 브라우저는 2초마다 서버에 생존 신호를 보내고, 서버는 6초간 신호가 없으면 제어권을 만료시킨다. 이때 OFF를 보내고 진동을 억제한다. 정상 USB 연결 기준 앱 종료부터 출력 중단까지 최대 7초를 시험 목표로 한다. 센서 수집과 기록은 서버가 실행되는 동안 계속한다. 모바일 브라우저가 백그라운드에서 중단되는 경우도 같은 방식으로 처리한다.

희망 진동 설정은 SQLite에 저장하지만, 장치 재연결 또는 제어권 재획득 시 기본 출력은 OFF다. 서버가 현재 설정을 다시 보내 ACK를 확인하고, 사용자가 제어를 재개한 뒤 새로운 조건에 대해서만 진동을 허용한다. 보드의 EEPROM에 매 프레임 기록하지 않는다.

C6.4 진동 중 센서 처리

진동 실행 동안과 종료 후 500ms는 좌우·등받이 판정의 갱신을 보류하고 품질 상태를 ‘진동 영향 구간’으로 기록한다. 원시 센서값은 계속 저장한다. 이 구간은 좌우·등받이 상태별 시간 집계에서 별도로 계산한다.

자리 비움을 놓치지 않도록 착석 여부 검사는 계속하되 낮은 좌판 반응이 1초 지속되는지 확인한다. 실제 진동이 빈 의자 판정을 방해하는지는 통합 시험으로 확인한다. 불안정하면 진동 크기·위치부터 조정하고, 관찰할 수 없는 구간을 임의로 정상이라고 기록하지 않는다.

C7 통신 및 API 설계

C7.1 시리얼 메시지

통신은 USB 시리얼 115200bps, 줄바꿈으로 구분되는 ASCII 메시지를 사용한다. UNO의 제한된 메모리를 고려하여 수신 버퍼는 96바이트로 고정하고 동적 String 누적을 피한다. 숫자 필드의 개수·범위·길이를 검사한다. 프레임 시각은 보드 millis 값과 서버 수신 시각을 모두 보존한다.

방향 형식 예시 의미
보드 → 서버 HELLO,1 펌웨어 부팅과 프로토콜 버전
서버 → 보드 INIT,38271 새 연결 세대 시작. 진동 OFF와 이전 명령 초기화
보드 → 서버 READY,38271 연결 세대 수락
보드 → 서버 S,38271,42,15300,120,125,130,128,80,82 세대·순번·보드 ms·A0–A5 원시값
서버 → 보드 HB,38271 현재 연결 세대의 생존 신호
서버 → 보드 SET,38271,7,0 명령 7번으로 진동 허용 OFF. 마지막 필드는 0 또는 1
서버 → 보드 VIB,38271,8,LEFT 명령 8번으로 정의된 패턴 요청

보드 → 서버 DONE,38271,8 패턴 완료 또는 중단. 상세 사유는 서버 명령과 대응

예시 수치는 프로토콜 설명용이다. S 프레임은 10Hz로 전송하고, HELLO는 시작 시 출력한다. INIT는 열린 포트마다 서버가 새로 생성하는 32비트 연결 세대 값을 사용한다. 초기 연결과 재연결에서 이전 세대의 명령과 ACK는 무시한다.

한 연결에서 명령 ID는 단조 증가한다. 서버는 일반 명령을 한 번에 하나씩 보내며, OFF와 STOP은 대기 중인 일반 명령을 취소하고 우선 전송할 수 있다. 보드는 가장 최근 처리 ID와 결과를 기억한다. 같은 ID의 재전송에는 저장된 결과만 응답하고 진동을 재시작하지 않으며, 더 작은 ID는 거부한다. OFF가 먼저 처리된 뒤 늦게 도착한 이전 진동 명령도 거부된다.

명령 ACK 타임아웃은 300ms로 시작하고 최대 두 번 재시도한다. 보드가 버퍼 길이를 넘는 입력을 받으면 해당 줄을 버리고 다음 줄바꿈부터 다시 읽는다. 알 수 없는 패턴·잘못된 값·현재 세대가 아닌 메시지는 출력에 반영하지 않는다. millis 오버플로는 부호 없는 시간 차이로 처리하고 장시간 실행 시험과 분리된 모의 시험으로 확인한다.

프레임의 좌우·등받이 상태가 UNKNOWN인 시간은 각 분모에서 따로 표시한다. 착석 시간은 좌우 상태와 별도로 집계할 수 있으나, 전체 측정 공백은 착석이나 휴식 어느 쪽에도 넣지 않는다. 이벤트 payload에는 알림의 원인과 설정 버전, 시연 모드를 포함한다.

C8.3 CSV 출력과 보관

세션 샘플과 이벤트는 각각 CSV로 제공한다. UTF-8 BOM을 사용하고 시각 열은 UTC ISO 형식, 지속 시간 열은 초 단위를 명시한다. 사용자가 입력한 가명이나 메모가 스프레드시트 수식으로 실행되지 않도록 =, +, -, @로 시작하는 텍스트를 이스케이프한다.

제출용 데이터는 가명 ID로 관리하고 해당 실험자가 동의한 범위에서 사용한다. 종료된 세션 삭제 기능으로 실험 원본을 제거할 수 있게 한다. 최종 보고서에는 표본 수와 실험 조건을 함께 기재한다.
