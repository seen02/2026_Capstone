# MAREA 디자인 미리보기

관람객 웹과 운영자 대시보드의 시각 디자인·정보 구조를 검토하는 독립된 정적 프로토타입입니다. 기존 `aquarium_sim`, `web`, `configs`는 수정하지 않습니다.

## 열기

이 폴더의 `index.html`을 브라우저로 열면 됩니다. 빌드·패키지 설치가 필요 없습니다. 상단 버튼으로 관람객 / 운영자를 전환합니다.

로컬 HTTP로 열려면 이 폴더에서 다음을 실행합니다. 기존 시뮬레이션 서버와 다른 포트를 사용합니다.

```powershell
python -m http.server 8766 --bind 127.0.0.1
```

브라우저 주소: http://127.0.0.1:8766 / 종료: Ctrl+C

## 폴더 구성

```text
web-admin/
├── index.html                       # 공통 진입점 및 화면 전환 바
├── frontend/
│   ├── app.js                       # 화면 전환·이벤트 연결
│   ├── apps/
│   │   ├── visitor/visitor.js        # 관람객 화면·전시 상세·선호 입력
│   │   └── operator/operator.js      # 운영 현황·구역 상세·안내판
│   └── shared/
│       ├── components/ui.js          # 공통 아이콘·SVG 지도·일러스트·모달
│       └── styles/
│           ├── tokens.css           # 공통 색·글꼴·디자인 토큰
│           └── app.css              # 화면 스타일·반응형
├── fixtures/demo-data.js             # 가상 데이터만 보관
├── contracts/README.md               # 추후 API 경계·연동 원칙
├── backend/README.md                 # 추후 서버 영역 (구현 없음)
├── database/README.md                # 추후 DB 영역 (구현 없음)
└── docs/
    ├── design.md                    # 디자인 방향·상태·적응형 규칙
    └── review.md                    # 검토 항목·구현 범위
```

## 범위

- 동작: 화면 전환, 관람 선호 모달, 고정 추천 경로 확인·선택 피드백, 전시 상세, 운영자 지도·구역 선택, 오늘/어제 가상 그래프 전환, 안내판·알림·설정 정보 모달.
- 미구현: 인증, 영구 저장, 실제 추천 계산, 실내 위치, 실시간 데이터, 장치 제어, API, DB, 실제 공연 예약.
- 모든 수치·시간·절약량·장치 상태·계정은 가상입니다. 혼잡 상태와 점유율 임계값은 디자인 설명용입니다.
- 전시 이름은 기존 프로젝트 A 연안 / B 산호 / C 심해 / D 해파리 / E 민물 / F 공연을 사용합니다. 지도는 UI 평가용 단순 도식이며 기존 이동 그래프와 연동되지 않습니다.
- 외부 CDN·폰트·이미지 요청은 없습니다. Pretendard가 설치되어 있으면 사용하고, 없으면 시스템 글꼴로 표시합니다. 따라서 컴퓨터마다 글꼴은 다소 다를 수 있습니다.
- 일반 script 순서로 로드하여 `file://`에서도 열립니다. 향후 실제 제품 구현에서는 모듈/빌드 체계와 데이터 접근 계층을 추가합니다.

디자인 시안 변경은 저장소의 커밋 이력으로 관리합니다.
