# 접힌 대기줄·넓은 광장 경로·성 앞 바닥 정리 검증

기준일: 2026-11-13. 매직아일랜드 3D 지도의 표시와 정적 안내 경로를 보완했다. 당시 서버는 지도 준비 상태인 `runnable: false`를 반환했다.

## 결과

- 6개 시설의 단순 대기 구획을 공연 대기줄 형태의 접힌 바닥 줄·금속 기둥·짙은 벨트·방향 화살표로 교체했다. 아쿠아리움 `web/map3d.js`의 공연 대기 표시 방식을 참고하고 `lotteworld/web/queue.mjs`로 독립 구성했다. 현재는 반원 회전부까지 양쪽 벨트를 연결하며 정적 자리 좌표와 최소 수용량을 검증한다. 자리 수는 화면에 표시하지 않는다. 최신 배치·검증은 [수용량·자동 반영 기록](queue-capacity-and-reload.md)을 따른다.
- 실제 다리 바닥만 남기고 섬 내부 그래프의 좁은 바닥 띠를 제거했다. 넓은 포장 면은 연속된 하나의 바닥으로 이어진다. 성 앞의 네모는 별도 `plaza` 바닥과 정면 연결 바닥이 길 바닥과 겹쳐 보이던 것이므로 중복 메시를 제거했다. 성 정문·다리의 직선 축과 논리적 광장 구획은 유지했다.
- 시설 선택 경로를 연결 그래프에서 광장 전체의 정적 경로 탐색으로 변경했다. `navigation.mjs`는 2m 격자와 반경 0.25m를 사용해 바다·성·건물·시설·대기/하차·식재 예약 구획을 피해 경로를 찾는다. 대각선 모서리 관통을 막고 통과 가능한 직선을 합친다. 입출구의 짧은 전용 접속부만 기존 지선을 이용한다. 화면의 거리는 이 표시 경로의 길이 합이다.
- 작은 화면 전체 보기에서는 대기줄 이름표를 숨기고 확대하면 보여 시설 이름표의 겹침을 줄였다. 대기줄 형상은 화면 크기와 무관하게 표시한다.

## 검증

| 검사 | 결과 |
| --- | --- |
| `lotteworld/`에서 `python -m unittest discover -s tests -v` | 13개 통과 |
| `development/`에서 같은 명령 | 5개 통과 |
| `node development/lotteworld/tests/route.test.mjs` | 기존 참조 경로 검사 통과 |
| `node development/lotteworld/tests/navigation.test.mjs` | 6개 표시 대기줄, 광장 경로, 장애물 우회, 경로 재사용 검사 통과 |
| `node development/lotteworld/tests/verify_map3d.cjs` | Chrome의 1600×1100·1024×900·390×844 통과 |
| 자작 JavaScript 모듈 문법·문서 링크·`git diff --check` | 통과 |

표시 대기줄의 입구와 모든 접힘·벨트가 대기 외곽 안에 있고 6개 모두 같은 규칙을 쓰는지 검사했다. 광장의 자유로운 두 점을 직접 잇고, 벽이 있는 별도 사례에서는 돌아가는지 확인했다. 실제 지도에서도 여러 시설의 안내 거리가 참조 그래프보다 줄어 광장을 활용하는지 검사했다. 경로 시작·끝과 좌표 길이 합, 실제 바닥 메시가 포장 면과 다리만으로 구성되는지도 확인했다.

브라우저에서는 전체 보기·시설 확대를 직접 확인하고 회전·확대·이동·시점 복귀·시설 선택·성 정문과 다리의 축·모바일 터치·실패 자원·외부 요청 여부를 확인했다. 캡처는 무시되는 `lotteworld/output/map3d-verification/`에 저장했다. Python 임시 폴더 쓰기와 브라우저 서버 실행이 샌드박스에서 차단된 검사는 허용된 실행 권한으로 다시 검사했다.

## 범위

포장 면 판정과 정적 안내 경로를 보완한 결과다. 사람의 생성·실시간 충돌 회피·밀도에 따른 우회, 실제 대기 합류·전진·이탈과 인원 상한 적용은 후속 단계다. 격자와 직선화로 구한 안내 경로는 연속 공간의 수학적 정확한 최단 경로나 현장 실측 이동시간이 아니다. 현재 대기열과 운영자 탭은 후속 검증에 기록했다. [물리적 대기열](magic-island-physical-queues-and-boarding.md) · [운영자 탭](magic-island-continuous-demo-ui.md)
