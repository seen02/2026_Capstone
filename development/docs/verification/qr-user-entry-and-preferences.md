# QR 사용자 진입과 선호 입력 검증

2026-11-18에 매직아일랜드 로컬 서버, Python 3.12, Playwright와 Chrome에서 확인했다. [로컬 실행 방법](../../lotteworld/README.md#qr-사용자-진입과-선호-입력)

| 검사 | 결과 |
| --- | --- |
| `python -m unittest discover -s tests -v` | 30개 통과. 별도 쿠키를 쓰는 두 동시 진입의 세션·캐릭터·좌표 분리, 같은 쿠키로 복구, 세션 ID로 자격 대체 불가, 미등록 표지판 거절을 확인했다. 개발용 기본 정책의 6개 시설 추천 회귀 검사도 통과했다. |
| 선호와 추천 연동 | 누락·중복·미등록 ID·자료형 오류를 거절했다. 유효한 저장으로 `awaiting_preferences`에서 `ready`로 전이했고 동일 저장 재시도의 revision은 유지됐다. 같은 위치에서 상위 두 시설의 순위를 바꾸자 추천이 자이로드롭에서 자이로스핀으로 바뀌었다. 응답의 경로 출발점은 저장한 캐릭터 위치였다. |
| 세션 수명과 충돌 | 서버 시각을 조정해 발급 후 29분 59초 재접속 시 만료 시각 유지, 정확히 30분에 조회·저장·추천 거절, 재진입 시 새 캐릭터와 기존 자리 재배정을 확인했다. 세션 교체나 모의 데이터 설정 변경 이후에는 이전 저장 요청이 거절됐다. |
| 표지판 안내 대상 | 방향 안내판 세 개의 대상만 선호 입력에 나타나고, 그 밖의 지도 시설 ID를 포함한 저장 요청은 거절됐다. 기본 시연 파일로 각 시설을 1순위에 저장하자 자이로스핀·혜성특급·자이로드롭이 각각 대기 300초·480초·900초로 추천됐다. |
| `node tests/verify_user_entry.cjs` | Chrome의 320×720·390×844 모바일 환경에서 같은 QR 주소로 독립 진입, 세 시설 표시, 터치 순위 저장, 혜성특급 1순위 저장 후 추천 응답, 가로 넘침 없음, 새로고침과 탭을 닫은 뒤 같은 브라우저 프로필에서 복구, 미등록 표지판 화면을 확인했다. 서버 주소는 `MAGIC_USER_URL`로 지정할 수 있다. |
| 지도·경로 회귀 | `node tests/route.test.mjs`, `node tests/navigation.test.mjs`, `node tests/verify_map3d.cjs`, 모의 경로 생성기 `--check` 통과. |

현재 지도 해시는 `6d2c5df534fef53ea2e248eb80a7cdaf7c7dbea93b865cd3fee398caf36ad052`다. 가상 표지판 `[101, 149]`m 중심에서 반경 12m 이내의 배치 후보를 생성하고 현재 지도와 `west-center` 연결을 검사했다. 유효한 102개 자리의 최소 중심 간격은 2m였다.

실제 휴대폰의 QR 스캔과 LAN 접속, AWS 배포는 미검증이다.
