# 디자인 평가 가이드

1. `index.html`을 열고 관람객/운영자 상단 전환 버튼을 누른다.
2. 관람객에서 관람 설정을 열어 전시·시간을 선택한 뒤 고정 추천 카드로 이동한다. 예시 경로 선택의 피드백을 확인한다.
3. 지도 구역·전시 카드를 눌러 상세를 확인한다. 공연을 눌러 설명을 확인한다.
4. 운영자 지도와 A~F 버튼을 선택한다. 인원·점유율·대기 시간·안내 문구가 선택 구역과 일치하는지 확인한다.
5. 오늘/어제 선택에 따라 그래프와 설명이 바뀌는지 확인한다. 실제 통계가 아닌 가상 비교다.
6. 안내판 관리, 알림, 운영 설정, 미리보기 안내를 연다. 모달은 닫기 버튼·Escape·바깥 영역 클릭으로 닫는다.
7. 창 너비 1440 / 1024 / 390px에서 가로 넘침, 줄바꿈, 터치 동작을 살펴본다.

## 평가 질문

- 관람객이 5초 안에 무엇을 누를지 알 수 있는가?
- 시간 비교와 추천 이유가 충분히 납득되는가?
- 운영자가 혼잡 구역을 발견하고 상세로 이동하기 쉬운가?
- 같은 브랜드이면서도 두 사용자에게 맞는 정보 밀도로 보이는가?
- 지도와 구역 명칭, 여유·보통·혼잡 상태가 명확한가?

네트워크 요청, 로그인, 데이터 저장, 장치 전송은 없다. 새로고침하면 모든 선택이 초기화된다.
