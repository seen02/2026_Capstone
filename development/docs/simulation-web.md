# 시뮬레이션 웹

현장 평가에서 전체 가상 공간을 큰 화면에 계속 띄워 두고 관찰하는 웹이다. 발표자는 지도에서 시설의 운영 지표를 확인하고 QR 캐릭터를 선택해 현재 위치와 추천 경로를 볼 수 있다. [소프트웨어 계획](software-plan.md) · [체크리스트](implementation-checklist.md)

## 기본 시연 화면과 시설 선택

기본 화면은 3D 지도가 화면 대부분을 채운다. 시뮬레이션과 운영자 대시보드는 Magic Pass 워드마크와 입장권 심벌, 짙은 보라색 상단 바, 금빛 선택 탭, 아이보리 패널을 공유한다. 지도 도구에서는 **전체 보기**와 **위에서 보기**로 시점을 바꾸고, 지도에서 회전·이동·확대할 수 있다. 시설 이름표는 지도 위에 표시하며 상세 패널은 시설을 선택하면 열린다.

| 상황 | 화면 동작 |
| --- | --- |
| 시설 찾기 | 지도 위 시설 모형이나 이름표를 선택한다. 키보드로는 Tab 키로 이름표에 초점을 맞추고 Enter 키를 누른다. |
| 시설 선택 | 큰 화면에서는 지도 오른쪽에 상세 패널을 연다. 좁은 화면에서는 지도 하단에 상세를 배치한다. 현재 시점에서 관찰을 계속할 수 있다. |
| 시설 확대·복귀 | 상세 패널의 시설명 옆 초점 버튼(네 모서리와 가운데 점)으로 시설을 확대한다. 지도 도구의 **전체 보기**로 처음 시점에 돌아간다. |
| 관찰 계속하기 | 닫기 버튼 또는 Esc 키로 상세 패널을 닫는다. |

기본 화면에는 배경 방문객의 현재 체류, QR 참여 인원과 시설별 코스 운행 여부가 표시된다. 시뮬레이션 시설 상세는 운행 상태·대기 인원·예상 대기·탑승 인원을 보여 준다. 대기줄 자리 수와 시간 표시·재생바는 시연 화면에서 숨긴다. [실행 방법](../lotteworld/README.md#실행)

배경 방문객 모형의 몸통과 팔다리는 좌측 하단 범례와 같은 색을 쓴다. 보행은 남색(`#26496b`), 대기는 갈색(`#753e06`)이다. 방문객이 시설의 초록색 대기 입구를 밟으면 갈색으로 바뀐다. 줄의 직선 구간과 반원 회전부 모두에 대기 자리가 있다. 두 지도에서 QR 캐릭터는 보라색(`#653caa`)으로, 발밑의 위치 표시 원은 금빛(`#f3cb79`)으로 표시한다.

## 연속 실행 관찰

전체 방문객·대기열·시설 운행과 QR 참여자의 캐릭터를 하나의 가상 공간에서 관찰한다. 지도 표식이나 QR 선택 목록으로 캐릭터를 선택하면 서버에서 받은 추천 목적지와 경로를 표시한다.

QR 참여자 상세 제목 옆의 따라가기 버튼은 네 모서리 안에 사람을 표시한다. 버튼을 누르면 선택한 캐릭터를 확대하고 카메라가 이동을 따라가며, 아이콘 속 사람만 보라색으로 채운다. 버튼을 다시 누르거나 상세를 닫거나, 지도를 직접 조작하거나 전체 시점으로 돌아가면 고정을 해제한다.

| 항목 | 시뮬레이션 웹의 역할 |
| --- | --- |
| 배경 방문객 | 좌표가 있는 보행자와 줄에 있는 방문객을 지도에 표시하고 탑승 인원은 시설 상세에서 표시 |
| QR 사용자 | 사용자 웹과 같은 가상 위치·진행 상태·추천 경로를 표시 |
| 시설 상태 | 코스 운행 여부는 시설 이름표에, 운행 상태·대기 인원·예상 대기·탑승 인원은 상세 패널에 표시 |

개별 사용자의 추천 수락과 보상 내역은 사용자 웹에서 다룬다. [사용자 웹](user-web.md)

## 운영자 대시보드 탭

로컬 시연의 시뮬레이션과 운영자 대시보드는 한 페이지 안에서 전환한다. `/`는 시뮬레이션, `/operator`는 운영자 대시보드로 직접 진입한다. 시뮬레이션 탭을 처음 열 때 3D 지도를 만들고, 탭 전환 중에는 지도 인스턴스와 카메라 위치·확대 배율·시설 선택을 유지한다.

두 탭은 하나의 `/api/state` 조회로 시설별 운행·대기·탑승 상태를 갱신한다. 운영 개요에는 시뮬레이션 방문객의 현재 체류 인원, 여섯 시설의 실제 대기 인원 합계, 최장 예상 대기의 시설명과 시간, 혼잡 시설 수를 표시한다. 대기 인원은 입구를 통과해 줄에 서거나 줄에서 전진하는 사람을 포함하며 탑승 이동을 시작하면 차감한다. 대기열 예약 자리 비율이 80% 이상인 시설을 혼잡으로 집계한다. 운영자 탭에서 여섯 시설의 상세를 조회할 수 있고, 조회가 지연되면 마지막으로 받은 값을 표시한다. 안내판 연결·현장 영상은 현장 데이터 연동 단계에서 제공한다.

시설별 운영 현황은 여섯 시설 버튼을 같은 크기로 두 열에 배치한다. 다리 쪽에서 매직캐슬 정면을 바라보는 방향으로 3D 지도 시설 좌표를 투영한다. 먼 시설부터 위쪽 행을 채우고, 각 행에서는 화면 왼쪽 시설부터 표시한다. 버튼 안에서 시설명과 대기 인원을 한 줄에 표시하고, 혼잡 시설에는 작은 **혼잡** 표시를 붙인다. 클릭하거나 키보드로 선택하면 시설 상세를 갱신한다. 시설 상세에는 운행 상태, 누적 회차와 합류 전 인원 등이 표시된다. 차량이 한 대인 시설은 **운행 상태**에 그 차량의 상태를 표시한다. 차량이 두 대 이상이면 **차량별 상태**에서 각 차량의 운행 상태와 승강장·코스 구간을 확인할 수 있다. PC 대시보드 본문은 창 높이에 맞춰 표시한다. 방문객 흐름 그래프는 서버가 시뮬레이션 1분마다 기록한 최근 2시간의 배경 방문객 누적 입장·누적 퇴장·현재 체류를 표시한다. 서버가 다시 시작하면 새 실행의 기록부터 표시한다.

PC 화면에서 요약 카드·윗줄·아랫줄의 높이는 13:42:45로 나눈다. 윗줄은 시설별 운영 현황과 방문객 흐름, 아랫줄은 시설 상세와 안내판 현황 순으로 배치한다. 패널 제목은 상단에 두며 시설 배치와 시설 상세의 본문은 제목 아래 남는 공간의 세로 가운데에 놓는다. 아트란티스의 운영 항목과 차량별 상태는 각각 두 열로 표시하며, 내용이 패널 높이를 넘으면 시설 상세 안에서 스크롤한다.

시설 상세는 대기 인원과 예상 대기를 먼저 표시하며, 안내판의 영상 미연결 영역은 밝은 배경을 사용한다.

시뮬레이션 3D 지도는 `/api/meta.signs`의 좌표에 놀이기구 방향 표지판을 표시한다. **위에서 보기** 기준으로 서쪽 안내판 `[123, 111]`m의 뾰족한 끝은 위쪽(자이로드롭), 왼쪽 위(혜성특급), 아래쪽(자이로스핀)을 향한다. 동쪽 안내판 `[242.8, 163.1]`m는 입구 다리와 아트란티스 대기줄 사이 녹지 가장자리의 포장면에 있으며 자이로스윙·아트란티스·아르카나라이드 입구 방향을 안내한다. 가장 낮은 판의 하단은 방문객 키의 약 1.24배, 기둥의 높이는 약 1.71배다.

운영자 대시보드에서는 시설별 운영 현황의 **안내판 버튼**에 아이콘과 안내판 이름을 표시한다. 놀이기구와 안내판 버튼은 호버하면 베이지 배경, 선택하면 보라색 테두리로 표시된다. **안내판 현황**에는 선택한 안내판의 대상 놀이기구 이름과 영상 영역이 표시된다. 영상 영역의 높이는 창 크기에 따라 바뀌며, 재생 영상은 원본 비율을 유지한다. 화면에 `video_url`을 읽는 재생 코드가 있다. 현재 서버는 `/api/meta.signs`에 영상 URL을 공급하지 않아 화면은 영상 미연결 상태를 표시한다.

보행 경로 계산과 화면의 보행 모형은 `map.geometry.signposts`에 설정된 기둥 주위를 우회한다. QR 참여자는 서쪽 안내판에서 입구 다리 쪽의 빈 보행 위치에 배정된다.

## 연속 시연과 엔진의 경계

- 현장 평가 시간은 **2시간**이다. 최소 2시간 연속 실행을 검증하며 수동 종료 전까지 계속 실행한다. 2시간이 지나거나 표시 시각이 한 바퀴 돌았다는 이유로 사용자 상태를 초기화하지 않는다.
- 서버는 연속 시연 설정으로 배경 방문객의 유입·개인 체류·퇴장을 실행하며 `GET /api/state`에 집계와 현재 체류 명단을 제공한다. [설정과 상태 계약](../lotteworld/docs/configuration.md#연속-시연-설정과-상태)
- 서버는 이동·대기·운행·갱신 시각을 내부 시간으로 계산한다. 배속은 서버 시작 시 읽는 연속 시연 설정에서 지정한다.
- 엔진은 인원·이동·줄·운행을 계산하고 공통 서버는 그 결과를 제공한다. 시뮬레이션 웹은 표시를 담당하며 사용자 웹과 서로 다른 캐릭터 이동을 계산하지 않는다.

## 공통 서버·사용자 웹과의 연결

두 웹은 기존 3D 지도·시설 자원을 재사용하고 같은 지도 버전·실행 문맥의 상태를 조회한다. 사용자 웹은 자기 세션 중심으로 표시하고 시뮬레이션 웹은 전체 공간을 표시한다. 같은 `character_id`의 위치·목적지·진행 상태가 두 화면에서 대응해야 한다. 추천 수락은 공통 서버를 통해 엔진 이동 명령과 연결한다. 보상 지급은 수락 확정을 기준으로 하는 후속 기능이다.

로컬 시연 웹은 같은 서버의 `/api/meta`와 `/api/state`를 사용한다. 조회에 실패하면 마지막 운영 상태의 갱신 지연을 알리고, 지도 해시가 다르면 운영 표시를 내린다. QR 추천은 이 실행의 시설별 예상 대기 시간을 사용한다. 배포 방식과 운영 URL은 후속 단계에서 정한다. [공통 계약](contracts/recommendation-v1.md)

## 화면 검증 기준

- 기본 화면에서 지도와 시설 이름을 한눈에 보고 회전·확대·이동, 위에서 보기, 시점 복귀, 전체 화면을 조작한다.
- 모형이나 이름표로 시설을 선택하면 상세가 열리고 카메라는 현재 시점을 유지한다. 이름표는 키보드로도 선택한다. 가까이 보기로 시점을 변경하고 닫기 버튼이나 Esc 키로 관찰 화면에 돌아간다.
- 큰 화면과 좁은 화면에서 패널과 지도 도구를 사용할 수 있다. 두 탭에 엔진에서 받은 운영 지표가 표시된다.

Chrome의 1920×1080·1024×900·390×844 화면에서 기본 지도 크기와 패널 조작, 선택 시 시점 유지 및 지도 조작을 확인했다. 큰 화면에서 전체 화면 전환과 복귀를 확인했고, 지도 설정 요청 실패 시 오류 안내가 나타나는 것도 확인했다. [브라우저 검증 스크립트](../lotteworld/tests/verify_map3d.cjs)

목표 부하에서 최소 2시간 연속 실행하며 인원 보존·세션 지속·메모리·응답·표시 성능을 검증하는 작업은 체크리스트 9번에서 진행한다. [배경 인원 순환 검증](verification/magic-island-continuous-arrivals.md)
