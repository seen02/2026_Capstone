보상은 이용 완료가 아니라 **유효한 추천 수락 확정**에 대해 지급한다. 계약·workflow 예제·계획·체크리스트·기존 인계 문구를 이 기준으로 수정했다. 위 2026-11-17 검사는 당시 초안의 기록이며 현재 보상 근거는 `RecommendationAccepted`다.

- 기준 브랜치 `main`, HEAD `f4369cce9b2a5858a304fa9d74884971529e03db`. 수정 전 작업 트리는 깨끗했다. 런타임 변경은 없다.
- `development/`에서 동일 Python 경로의 `python -`에 일회성 대조 스크립트를 전달했다. 추천·명령·수락 응답·수락 이벤트·보상의 ID/context/source 연결과 예제의 `수락 확정 → 보상 지급 → 이후 이용 완료` 시각 순서 검사가 통과했다.
