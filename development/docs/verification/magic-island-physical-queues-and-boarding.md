[선행 정적 배치 검증](queue-capacity-and-reload.md)

서버의 경로 검증은 대기·탑승·이탈 경로와 벨트 및 기둥 받침 사이에 방문객 반경만큼 여유가 있는지 확인한다. 대기와 이탈의 평행 보행에는 두 방문객의 반경을 합한 간격을 적용한다. 입구의 마지막 구간은 게이트 중앙으로 곧게 접근하며, 황금색 탑승 진입점 직전에는 완만한 모서리로 보행 간격을 확보한다. 시설에서 나온 방문객은 하차 합류 구획의 빨간 점을 통과한 뒤 `exit` 지선으로 공공 보행 면에 복귀한다. [경로 구현](../../lotteworld/lotteworld_sim/visitor_routes.py)

## 실행 검증

- 가속 시계에서 초기 1,500명을 내부 12시간 진행했다. 여섯 시설이 각각 예약 상한에 도달하는 사례, 만석 입구에서 다른 시설로 향하는 움직임, 방문객 인원 보존과 한 자리 한 명을 확인했다. 당시에는 시설이 모두 만석이면 공공 광장의 접근 연결점을 순회했다. 이후 포장면에서 목적지를 무작위로 고르는 방식으로 갱신했다. 진입 지점의 직각 구간에서 몸체가 겹치지 않도록 최소 경로 간격을 1m로 정하고 촘촘한 시각 표본으로 재검증했다. 초기 240명 조건에서는 줄 중간 이탈자의 자리 해제 후 뒤 방문객 전진과 체류 만료 방문객의 실제 다리 퇴장을 확인했다. [런타임 테스트](../../lotteworld/tests/test_physical_queues.py) · [현행 광장 산책 검증](magic-island-visitor-behavior.md#광장-산책과-걷는-도중-시설-선택)
- 여섯 시설에서 1회 탑승 정원 전체를 선두 순서대로 보내고 탑승 지점에 도착한 뒤 한 묶음을 하차시켰다. 빨간 점 통과 간격은 1 내부 초이며, 전용 하차 경로에서 방문객 몸체 반경의 합인 0.6m 이상을 확보한다. 주행 경로의 꺾이는 구간에도 간격 검사를 적용했다. 체류 만료가 탑승 접근 중 발생하면 하차 후 다리 방향으로 돌아간다. [런타임 테스트](../../lotteworld/tests/test_physical_queues.py)
- 매직아일랜드 Python 39개와 개발 루트 Python 5개, Node 경로·배치 2개를 실행했다. Chrome 1920×1080·1024×900·390×844 지도에서 서버와 동일한 줄·벨트·이탈 좌표 및 지도 조작을 확인했다. Chrome 320·390px 모바일 QR에서는 세션 분리·선호 저장과 복구를 확인했다.

시연 가정으로 보행 속도는 내부 초당 1.4m, 하차 시작 간격은 1 내부 초를 사용한다. 최대 대기시간과 실제 회차·차량 처리량은 5–6번 연결 후 측정한다. 공공 광장의 인파 충돌 회피와 3D 방문객 표시, 현장 2시간 연속 시험은 후속 항목에서 다룬다.

## 시설 전용 구역과 하차 분산

지도 시안의 주황선을 기준으로 놀이기구 여섯 곳의 탑승·하차 통로와 대기열 주변을 전용 구역으로 두었다. 공용 보행, 광장 산책, 추천 경로의 공용 구간은 이 구역을 피해 이동한다. 입구 앞 공용 접근점과 전용 통로의 경계를 연결해, 해당 시설에 진입하거나 탑승·하차하거나 대기열을 이탈하는 방문객의 지정 경로가 이어지도록 했다.

초록 대기 입구와 빨간 하차점은 기존 지도 좌표를 사용한다. 배경 방문객은 빨간 점을 순서대로 통과하고, 그 직후부터 시설·대기열·녹지를 피해 여러 경로로 흩어진다. 공용 보행면에 합류한 뒤 각자의 다음 시설 또는 다리로 향한다. [경로 구현](../../lotteworld/lotteworld_sim/visitor_routes.py) · [설정·상태 계약](../../lotteworld/docs/configuration.md#물리적-대기열과-승하차-보행)

자이로스윙과 아트란티스는 3개, 나머지 네 시설은 5개의 하차 경로를 사용한다. 빨간 점까지의 좌표와 이동 거리는 같은 시설의 모든 경로에서 같고, 이후 분기와 공용 합류점까지의 보행 여유와 거리 차를 검사한다. 빨간 점에서 경로를 따라 3.5m 이동한 시점의 경로 간 최대 거리는 시설별로 약 1.2~4.1m였다.

지도 13건, 방문객 행동 16건, 물리 대기열 7건, 운행 10건, 추천 13건과 JavaScript 경로·위치 보간 검사가 통과했다. 1,500명 격리 Chrome에서 실제 공용 보행 모형의 화면 좌표 15,783건을 확인해 전용 구역 진입 0건을 기록했다.

1,500명 격리 실행의 내부 350~600초에서 11개 시점을 표본 검사했다. 공용 보행 좌표 7,592개는 여섯 전용 구역 밖에 있었고, 각 시설 쪽 전용 하차 좌표 341개와 전용 탑승 이동 좌표 241개에서 다른 시설 전용 구역 침범이 없었다.

3000번 서버 재시작 후 지도·상태·모의 추천의 해시가 일치했다. 실제 상태 표본에서 일반 보행자는 전용 구역 바깥에 있었고, 자이로드롭의 전용 구역에서 해당 시설 하차객의 이동을 확인했다.
