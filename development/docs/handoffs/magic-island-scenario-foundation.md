## 완료 결과와 결정

- `development/aquarium/`: 기존 패키지·지도·운영·선호·스크립트·테스트·웹 화면·정적 `web-admin`·기존 설계/재사용 문서 전체. 이 폴더에서 기존 서버·CLI·`run.ps1`을 실행한다.
- `development/lotteworld/`: 새 독립 패키지 `lotteworld_sim`, 전용 설정·서버·CLI·테스트. 아쿠아리움 모듈을 import하지 않는다. 두 폴더는 각자 단독 복사해 실행할 수 있다.
- 개발 루트의 [run.py](../../run.py)는 `--scenario aquarium|magic-island`, `--mode server|cli`로 별도 프로세스·작업 폴더를 선택한다. 시나리오는 필수이며 기본값으로 추정하지 않는다. 명시한 설정·출력 경로는 호출한 폴더 기준이다.
- 아쿠아리움 기본 포트는8765, 정적 시안은8766, 매직아일랜드 설정 서버는8767이다. 기본 아쿠아리움 동작과 기존 API·Python 함수 호출은 유지한다.
- 매직아일랜드 `/api/meta`는 독립 지도·운영·선호와 해시를 반환한다. 현재 `configuration_only`, `runnable: false`이며 지도는 `planned`, `geometry: null`이다. 재생·상태 API는409, 없는 경로는404다. CLI는 `--validate-only`에서만 설정을 내보내며 시뮬레이션 보고서를 만들지 않는다.

## 결정과 제약

- 사용자 요청으로 실제 코드·문서 위치까지 분리했다. 해양 전시 선호·공연·폐장 처리를 매직아일랜드 실행으로 가져오지 않는다.
- 6개 시설은 아트란티스·자이로드롭·자이로스윙·자이로스핀·혜성특급·아르카나라이드다. 쁘띠빵빵은 제외한다.
- 관측10:00~19:00, 계획 유입10,350명, 실제 진입부터 대기 포함 예정 체류120~240분. 19시는 월드 오브 라이트 시작에 따른 관측 종료이며 폐장이 아니다. 시간표·출처·가정은 [명세](../design.md)·[운영 조사](../magic-island-research.md)가 기준이다.
- 선호 JSON의 동일 선호 기준형은 계약 검증용 가정이다. 방문객 행동 정책은7번에서 구현한다.
- 체크 항목 하나가 새 채팅 하나의 작업 단위다. 관련 검증과 문서 갱신까지 마친 뒤 체크한다. 안내판 효과·대피·DB·인증·제품 시안 연동은 후속 범위다.
- 사용자 대상 문구는 한국어, 호칭은 태인님이다. 완료 답변에 캡처 이미지는 별도 요청 때만 제공한다.

## 연결 지점

1. [개발 지침](../../AGENTS.md), [명세](../design.md), [체크리스트](../implementation-checklist.md)를 먼저 확인한다.
2. [시나리오 계약](../../lotteworld/lotteworld_sim/scenario.py)의 `load_inputs`, `validate`, `Scenario.metadata`와 [계약 문서](../../lotteworld/docs/configuration.md): 현재 미구현 지도 계약을 실제 지도 스키마로 확장할 지점이다. 지도 형상만 구현해도 보행·운행 실행 가능 여부는 따로 판단한다.
3. [지도 설정](../../lotteworld/configs/map.json): 현재 시설 ID6개만 있다. 가이드맵의 상대 배치를 참고하되 가독성을 위해 동선 공간을 넓힌다. 성·호수·다리·각 시설 입출구·대기 구획을 독립 좌표계로 추가한다.
4. [전용 서버](../../lotteworld/lotteworld_sim/server.py): 현재 준비 상태 HTML과 메타데이터만 제공한다. 아쿠아리움 화면을 통째로 복사해 새 지도와 섞지 않는다.
5. 필요할 때만 [기존 보행 엔진](../../aquarium/aquarium_sim/movement.py)·[기존 지도 생성](../../aquarium/scripts/build_map.py)·[아쿠아리움 설계](../../aquarium/docs/design.md)를 참고한다. 그대로 import해 실행 경계를 결합하지 않는다.

## 검증

실제 명령·결과·검사 범위는 [시나리오 분리 검증 기록](../verification/scenario-isolation.md)에 정리했다. 기본 설정의 합계·교차 참조, 오류 입력, 서버·CLI 선택, 단독 복사 실행, 기존 아쿠아리움 회귀와 JavaScript 검증이 대상이다. 실제 매직아일랜드9시간 실행·지도 공간·대기열·차량 운행은 이번 검증 대상이 아니며 미구현이다.

Windows의 `python`이 WindowsApps 별칭이면 `C:/Users/admin/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/python.exe`를 사용한다. 각 폴더의 `run.ps1`도 이 런타임을 우선 사용한다.

## 재개 순서와 남은 문제

1. 현재 브랜치·변경 상태와 `lotteworld/`의 설정 계약만 대조한다.
2. 체크리스트2번의 지도·시설 표시를 구현하고 실제 지도 스키마·검증을 갱신한다. 시간표 실행·체류·대기열·운행은 후속 항목에 남긴다.
3. 지도 연결성·구획·시설 구별과 관련 회귀를 검사하고 문서를 갱신한 뒤2번을 체크한다.

시설별 미확인 운행시간·차량 수와 대기 공간 정원은 아직 남아 있다. 지도 작업에서 외곽 구획은 잡되 최종 대기 자리 수는4번, 운행 값은5~6번에서 근거·가정과 함께 정한다.
