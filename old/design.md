# 자리 — 팀 소개용 목업 디자인

참고: [DesignMD Minimal SaaS Dashboard 공개 가이드](https://designmd.directory/t/minimal-saas-dashboard-designmd). 공개된 색상 역할, 4px 간격 체계와 한 화면에 한 가지 작업이라는 원칙을 참고했다. 유료 소스는 사용하지 않았다.

- 목적: 처음 보는 팀원이 자세 감지, 휴식 코칭, 진동 ON/OFF를 30초 안에 이해한다.
- 배경은 따뜻한 회색, 카드에는 흰색, 주요 글자는 짙은 먹색. 파란색은 센서 반응과 핵심 행동에 집중한다.
- 간격은 4/8/12/16/24/32px, 모서리는 12~20px. 장식과 중복 설명은 줄인다.
- 첫 화면은 시연 조작 → 자세 확인 → 휴식 시간 → 진동 알림 순서. 상세 기록은 기록 탭으로 이동한다.
- 센서 숫자보다 현재 상태 문장을 강조한다. 전문 용어 대신 '균형 있게 앉아 있어요', '잠깐 일어나 볼까요'처럼 행동이 드러나는 문구를 쓴다.
- 튜토리얼은 첫 방문에 자동 표시한다. 강조 테두리와 화살표가 달린 설명 상자로 5단계를 안내하며 이전/다음/건너뛰기/Escape/다시 보기를 지원한다.
- 튜토리얼 동안 시뮬레이션 시간은 정지한다. 진동은 실제 장치가 아닌 화면상의 시연임을 표시한다.
- 모바일은 한 열로 배치하고 튜토리얼 상자는 화면 밖으로 나가지 않도록 배치한다.
