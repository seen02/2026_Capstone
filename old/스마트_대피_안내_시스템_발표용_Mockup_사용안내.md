# 스마트 대피 안내 시스템 — 발표용 Mockup 사용 안내

**실행 파일:** [스마트_대피_안내_시스템_발표용_Mockup.html](스마트_대피_안내_시스템_발표용_Mockup.html)

파일을 Chrome 또는 Edge에서 열면 바로 실행됩니다. 설치·인터넷·서버가 필요 없습니다. 기존 v2는 보존하고 발표용 화면을 별도 파일로 만들었습니다.

## 처음 보는 관객에게

“통로에 사람이 몰리거나 위험 때문에 길이 막히면, 각 갈림길의 표지판이 대피 방향을 다시 고르는 시스템입니다.”

지도 아래 **파란 ‘현재 위치’가 출발점**입니다. 오른쪽의 큰 화면은 그 입구에서 보게 될 표지판입니다. 지도 안의 작은 표지판 2개는 왼쪽·오른쪽 구역에서 각자 판단한 결과입니다. 움직이는 점선은 안내 방향을 설명하는 효과이며 사람의 이동이나 실측 경로가 아닙니다.

## 발표 당일

1. 브라우저 확대를 100%로 맞추고 **F** 또는 ‘전체 화면’을 누릅니다.
2. **‘90초 자동 시연’**을 누르면 네 장면이 순서대로 진행됩니다.
3. 직접 설명하며 넘기려면 **→ / ←** 또는 하단의 다음·이전 버튼을 사용합니다.
4. **‘발표 대본’**에는 그대로 읽을 수 있는 90초 대본이 있습니다. 자동 시연 중 열면 계산과 진행 시간이 멈춥니다. 닫은 뒤 ‘이어서 재생’을 누릅니다.
5. 마지막에는 네 장면의 핵심을 정리하고 종료합니다. 자동으로 반복하지 않습니다.

| 시간 | 장면 | 관객이 봐야 할 변화 | 말할 핵심 |
|---|---|---|---|
| 0–25초 | 평소 | 입구의 왼쪽 화살표 | 위험·혼잡이 없으면 가까운 출구 A |
| 25–45초 | 왼쪽 통로 30명 | 확인 타이머 → 오른쪽 화살표 | 5초간 확인 후 혼잡을 피해 출구 B |
| 45–65초 | 오른쪽 통로 차단 | 왼쪽으로 즉시 변경 | 왼쪽이 붐벼도 위험한 오른쪽은 제외 |
| 65–90초 | 두 출구 통로 차단 | 화살표 대신 X | 안내 가능한 경로가 없음을 표시 |

혼잡 장면의 5초 동안 큰 화살표는 **현재 출력**을 유지합니다. 아래 ‘변경 확인 중’에 표시되는 화살표는 아직 적용되지 않은 후보입니다. 위험 장면에서는 이 대기 없이 차단된 경로를 제외합니다. 혼잡 장면에서는 전환을 확인할 수 있도록 5초 확인이 끝날 때까지 다음 버튼과 → 키를 잠시 막습니다. 숫자키나 장면 버튼으로 특정 장면에 직접 이동할 수는 있습니다.

## 부스에서 직접 체험

‘직접 체험’을 켜면 가상 인원 슬라이더, 통로 차단 스위치, 연결 장애 시험이 나타납니다.

- **혼잡:** 왼쪽 통로 인원을 늘리고 입구와 왼쪽 표지판의 변화를 봅니다.
- **위험 우선:** 혼잡으로 오른쪽을 안내하는 상태에서 오른쪽 통로를 차단합니다.
- **인원 정보 단절:** 마지막 인원값을 유지하다 5초 뒤 거리 기준으로 전환합니다.
- **오른쪽 표지판 끄기:** 표지판 출력이 꺼집니다. 3초 뒤 오른쪽 통로의 정상 정보가 미확인이 되며, 확인된 대안 경로가 있으면 우회합니다. 이전에 차단된 정보는 유지합니다.
- **인원만 초기화:** 위험·연결 상태를 유지합니다.
- **위험 해제·연결 복구:** 현재 인원은 유지합니다.
- **판단 기록 저장:** 현재 조건·모의 계산·이전 장면의 기록을 JSON으로 저장합니다.

장면 01–04 버튼은 발표를 반복할 수 있도록 **해당 장면의 인원·위험·연결 조건을 새로 불러옵니다.** ‘인원만 초기화’와 다른 기능입니다.

## 단축키

| 키 | 기능 |
|---|---|
| 1–4 | 해당 장면 불러오기 |
| → / ← | 다음 / 이전 장면 |
| Space | 자동 시연 시작 / 일시정지 / 이어서 재생 |
| R | 첫 장면으로 복귀 |
| F | 전체 화면 |
| P | 상단 도구 숨기기 / 다시 표시 |
| N | 발표 대본 |
| E | 직접 체험 조작 열기 / 닫기 |
| Esc | 열린 설명창 닫기 |

브라우저 탭을 다른 곳으로 이동하면 자동 시연은 일시정지됩니다. 화면으로 돌아온 뒤 ‘이어서 재생’을 누릅니다.

## 구현 범위

이 파일은 **가상 공간·고정 인원 분포·경로 계산을 브라우저에서 보여주는 소프트웨어 목업**입니다. 실제 ESP32, ESP-NOW, LED, 위험 스위치, 사람 위치는 연결되어 있지 않습니다. 실제 대피 시간이나 하드웨어 지연을 측정한 결과가 아닙니다.

거리·혼잡 비용, 15% 개선 기준, 후보 5초·방향 유지 5초, 위험 즉시 제외, 정보 만료, 인원 초기화와 위험 분리는 계획서 v2의 규칙을 사용합니다. X는 안내 가능한 경로가 없다는 뜻이고, ?는 정보 부족으로 확정할 수 없다는 뜻입니다.
