# 향후 데이터베이스 영역

2026-11-11 최신 기준은 [매직아일랜드 개발 명세](../../../docs/design.md)이며 DB 도입은 1차 필수 조건이 아니다. 향후 저장 시 시나리오·지도/설정 해시·시드·출처·가정 계수와 시간별 계획/실제 진입·복귀·잔류·미진입을 구분한다. 19시 관측 종료의 진행 중 대기·탑승을 미완료 상태로 보존한다. 계획 유입 10,350명과 대기 포함 개인 예정 체류 120–240분은 실험 설정이지 현장 관측 기록이 아니다.

예약 영역이며 DB·스키마·마이그레이션은 아직 없다. 실제 DB 종류도 미선정이다.

향후 후보 데이터는 시나리오별 구역·놀이시설·차량·운행 회차·실험 이력, 장치·혼잡 이벤트·운영 계정이다. 기존 아쿠아리움 공연 회차와 놀이시설 회차는 구분한다. 시뮬레이션 실험과 현장 관측은 출처를 구분한다. 경로·선호를 영구 저장할 필요성과 익명 세션 정책은 요구사항을 정한 후 결정한다.

DB를 도입하면 스키마·마이그레이션·개발용 시드를 이 영역에서 관리한다. 화면용 `fixtures/`를 실제 DB 시드나 관측 기록으로 취급하지 않는다. 프런트엔드는 DB에 직접 연결하지 않고 백엔드 API를 사용한다.
