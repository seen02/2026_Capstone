# 매직아일랜드 연속 유입·개인 체류·퇴장 검증

2026-11-19에 체크리스트 3번을 검증했다. 서버 시작부터 수동 종료까지 배경 방문객이 개인별 체류를 마치고 퇴장하며 빈자리가 순차적으로 보충된다. `GET /api/state`는 실행 ID, 내부 경과 시간과 누적 진입·현재 체류·누적 퇴장을 제공한다. [설정·API 계약](../../lotteworld/docs/configuration.md#연속-시연-설정과-상태)

## 인원·체류 기본값의 근거

- 초기 검증은 배경 방문객 240명으로 인원 순환과 QR 회귀를 확인했다. 같은 시연 모형의 1,500명 조건도 비교했다. 두 인원은 매직아일랜드 실측치가 아닌 시험 부하다.
- 기본 체류는 내부 시간 120~180분 균등분포다. 시설 4개를 기준으로 이동·대기·탑승에 시설당 평균 30~45분을 배정할 수 있다. 희망 이용 횟수는 3~4개이며, 실제 이용 가능 횟수는 시설별 대기·운행과 경로를 연결한 뒤 확인한다. 내부 6배속에서 신규 방문객의 체류는 실제 20~30분에 해당한다.
- 빈자리가 생기면 내부 5초마다 한 명씩 보충한다. 만석일 때는 입장 수요를 누적하지 않는다. 이 방식의 최대 보충 속도는 내부 시간당 720명이며, 1,500명이 평균 2.5시간 체류할 때 필요한 평균 보충은 시간당 약 600명이다.

## 결과

| 가속 조건 | 현재 체류 범위 | 마지막 누적 진입 | 마지막 현재 체류 | 마지막 누적 퇴장 |
| --- | ---: | ---: | ---: | ---: |
| 기본 240명, 실제 2시간에 해당하는 내부 12시간 | 237~240명 | 1,401 | 240 | 1,161 |
| 비교 1,500명, 같은 내부 12시간 | 1,480~1,500명 | 8,688 | 1,499 | 7,189 |
| 기본 240명, 내부 14일 | 목표 이하 | 32,471 | 240 | 32,231 |

- 내부 12시간 집계는 실제 시간 1초에 해당하는 간격으로 표본을 읽은 결과다. 내부 14일의 자동 검사는 반복 순환 중 인원 보존·상한, 현재 명단의 ID 고유성, 개인 체류 범위와 같은 시드의 재현성을 확인했다. 빈 시작에서 보충이 시작되는 시점과 퇴장·입장 동시 시각도 확인했다. [배경 순환 테스트](../../lotteworld/tests/test_background.py)
- 로컬 서버의 내부 시계를 가속하고 첫 HTTP 요청 전에 누적 퇴장이 진행된 것을 확인했다. 첫 `GET /api/state`는 내부 6시간 기준 누적 진입 814명, 현재 체류 240명, 누적 퇴장 574명을 반환했다.
- 두 브라우저 세션에 서로 다른 선호를 저장하고 배경 방문객을 여러 차례 교체했다. 실행 ID가 유지됐고 같은 쿠키로 세션·캐릭터·선호·모의 추천을 조회했다. 당시 QR 만료 기준은 실제 시간 30분이었다. 현재는 마지막 접속 신호 후 5분에 자동 만료되며 실시간 추천과 수락을 지원한다. 보상 지급은 후속 작업이다. [최신 QR 검증](qr-user-entry-and-preferences.md)
- CLI 설정 검증, Python 단위·HTTP 통합 테스트 35개, Node 지도 경로 테스트 2개, Chrome 3D 지도와 모바일 QR 회귀가 통과했다. Windows 제한 환경에서 Python 테스트의 임시 디렉터리만 작업 폴더 아래에 기본 권한으로 생성했다.
- 이 기록은 배경 인원 순환과 지도·QR 회귀를 다룬다. 보행·운행·화면의 인원 표시를 연결한 실제 2시간 연속 실행과 성능 측정은 체크리스트 9번에서 수행한다. [구현 체크리스트](../implementation-checklist.md#연속-시연-엔진과-지도-개발)
