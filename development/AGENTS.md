## 사용자 응답 선호

- 작업 완료 답변에 캡처 이미지를 보내지 않는다. 사용자가 별도로 요청한 경우에만 제공한다.

## 커밋 컨벤션

- 커밋 제목은 `type(scope): 변경 내용` 형식으로 작성한다. `scope`는 기능 또는 모듈을 나타내는 짧은 영어 소문자 이름으로 반드시 포함하고, 변경 내용은 한국어로 작성한다.
- 기능 추가는 `feat`, 버그 수정은 `fix`, 문서는 `docs`, 동작 변경 없는 구조 개선은 `refactor`, 테스트는 `test`, 기타 유지보수는 `chore`를 사용한다.
- 기능 단위로 커밋하며 제목은 실제 변경 내용을 구체적으로 표현한다.
- 범위 예시: `config`, `simulation`, `map`, `playback`, `project`.
- 예시: `feat(simulation): 페르소나 관람과 공연 대기 시뮬레이션 구현`, `docs(project): 실행 방법과 설계 및 개발 작업 기준 정리`.
