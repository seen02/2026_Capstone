# 시뮬레이션 웹

현장 평가에서 전체 가상 공간을 큰 화면에 계속 띄워 두고 관찰하는 웹이다. 발표자는 설명이 필요할 때 지도에서 시설을 선택한다. 현재 구현은 정적 3D 지도와 시설 선택 패널, 참조 동선을 제공한다. [소프트웨어 계획](software-plan.md) · [체크리스트](implementation-checklist.md)

## 기본 시연 화면과 시설 선택

기본 화면은 3D 지도가 화면 대부분을 채운다. 상단에는 작은 제목과 지도 상태, 브라우저 전체 화면 조작을 배치한다. 지도 도구 모음에는 **전체 보기**, **위에서 보기**, **시설 찾기**를 함께 둔다. 지도에서 회전·이동·확대를 조작할 수 있다. 시설 목록과 상세 패널은 처음에 접혀 있으며 시설명은 지도 위에 표시한다.

| 상황 | 화면 동작 |
| --- | --- |
| 시설 찾기 | 지도 위 시설 모형이나 이름표를 선택한다. **시설 찾기**를 누르면 여섯 시설의 목록이 열리며 키보드로도 선택할 수 있다. |
| 시설 선택 | 큰 화면에서는 지도 오른쪽에 상세 패널을 연다. 좁은 화면에서는 지도 하단에 상세를 배치한다. 현재 시점에서 관찰을 계속할 수 있다. |
| 동선 설명 | 상세 패널에서 동선 보기를 눌러 선택 시설의 대기 입구·탑승 진입·이용 후 퇴장 표식을 강조하고 다리와 연결되는 입구 접근·퇴장 복귀 참조 경로를 표시한다. |
| 시설 확대·복귀 | 상세 패널의 가까이 보기로 시설을 확대하고 지도 도구의 전체 보기로 처음 시점에 돌아간다. |
| 관찰 계속하기 | 닫기 버튼 또는 Esc 키로 상세 패널을 닫는다. |

현재 화면은 정적 지도 상태를 안내한다. 관람객 수·대기 인원·예상 대기시간·운행 상태는 실제 엔진 데이터가 연결되는 단계에서 표시한다. 대기줄 자리 수와 시간 표시·재생바는 시연 화면에서 숨긴다. [실행 방법](../lotteworld/README.md#실행)

## 엔진 연동 후 관찰 항목

전체 방문객·대기열·시설 운행과 QR 참여자의 캐릭터를 하나의 가상 공간에서 연속 관찰한다. 기본 시점에서 전체 흐름을 보고 시설이나 사람을 선택하면 상세 상태와 목적지를 확인한다. 캐릭터 선택 시 경로를 강조하고 발표자가 원할 때 따라볼 수 있게 한다.

| 항목 | 시뮬레이션 웹의 역할 |
| --- | --- |
| 전체 방문객 | 배경 방문객과 QR 사용자 캐릭터의 이동·대기·탑승을 표시 |
| QR 사용자 | 사용자 웹에서 수락한 목적지와 연결된 같은 캐릭터를 표시 |
| 시설 상태 | 엔진이 제공하는 대기열·운행 상태를 지도와 상세 패널에 표시 |

개별 사용자의 추천 수락과 보상 내역은 사용자 웹에서 다룬다. 현장 영상과 시설 현황을 다루는 관리자 대시보드와의 통합 여부는 미정이다. [사용자 웹](user-web.md)

## 연속 시연과 엔진의 경계

- 현장 평가 시간은 **2시간**이다. 최소 2시간 연속 실행을 검증하며 수동 종료 전까지 계속 실행한다. 2시간이 지나거나 표시 시각이 한 바퀴 돌았다는 이유로 사용자 상태를 초기화하지 않는다.
- 기존 10:00–19:00·총유입 10,350명은 이전 시간표 설정이다. 현재 서버는 별도 설정으로 배경 방문객의 유입·개인 체류·퇴장을 실행하며 `GET /api/state`에 집계와 현재 체류 명단을 제공한다. [설정과 상태 계약](../lotteworld/docs/configuration.md#연속-시연-설정과-상태)
- 시간 표시를 숨겨도 이동·대기·운행·갱신 시각을 계산하는 내부 시간은 유지한다. 개발용 시작/정지·초기화·배속·진단 조작은 필요할 때 별도 개발 화면 또는 실행 설정으로 제공한다.
- 엔진은 인원·이동·줄·운행을 계산하고 공통 서버는 그 결과를 제공한다. 시뮬레이션 웹은 표시를 담당하며 사용자 웹과 서로 다른 캐릭터 이동을 계산하지 않는다.

## 공통 서버·사용자 웹과의 연결

두 웹은 기존 3D 지도·시설 자원을 재사용하고 같은 지도 버전·실행 문맥의 상태를 조회한다. 사용자 웹은 자기 세션 중심으로 표시하고 시뮬레이션 웹은 전체 공간을 표시한다. 같은 `character_id`의 위치·목적지·진행 상태가 두 화면에서 대응해야 한다. 추천 수락은 공통 서버를 통해 엔진 이동 명령과 연결하고 보상은 수락 확정 이벤트를 기준으로 처리한다.

실제 URL·별도 배포 여부와 상태 전송 방식은 미정이다. 데이터의 출처·시간·문맥은 [공통 계약](contracts/recommendation-v1.md)을 따른다. 모의 추천 현황을 실제 이동·대기·운행 결과로 표시하지 않는다.

## 화면 검증 기준

- 기본 화면에서 지도와 시설 이름을 한눈에 보고 회전·확대·이동, 위에서 보기, 시점 복귀, 전체 화면을 조작한다.
- 모형·이름표·목록에서 시설을 선택했을 때 상세가 열리고 카메라는 현재 시점을 유지한다. 동선 보기와 가까이 보기로 각각 경로 표시와 시점 변경을 조작하며 닫기 버튼과 Esc 키로 관찰 화면에 돌아간다.
- 큰 화면과 좁은 화면에서 패널과 지도 도구를 사용할 수 있고, 정적 지도 상태에서 인원·대기·운행 수치가 나타나지 않는다.

Chrome의 1920×1080·1024×900·390×844 화면에서 기본 지도 크기와 패널 조작, 선택 시 시점 유지, 동선 전환 및 기존 지도 조작을 확인했다. 큰 화면에서 전체 화면 전환과 복귀를 확인했고, 지도 설정 요청 실패 시 오류 안내가 나타나는 것도 확인했다. [브라우저 검증 스크립트](../lotteworld/tests/verify_map3d.cjs)

엔진 연동 단계에서는 지도에 실제 이동·대기·운행이 표시되고 사용자 웹의 같은 캐릭터와 상태가 일치하는지 확인한다. 목표 부하에서 최소 2시간 연속 실행하며 인원 보존·세션 지속·메모리·응답·표시 성능을 검증한다. 현재 화면은 정적 지도이며, 배경 인원 순환 상태는 API에서 검증했다. [연속 시연 검증](verification/magic-island-continuous-arrivals.md)
