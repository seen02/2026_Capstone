# 향후 백엔드 영역

2026-11-11 최신 요구사항은 [매직아일랜드 개발 명세](../../../docs/design.md)다. 1차는 기존 시뮬레이션을 바탕으로 지도·보행·대기열·반복 탑승을 개발하며 이 폴더의 별도 서비스·인증·제품 연동은 필수 조건이 아니다. 10:00~19:00은 관측 구간이고 19시 폐장 이벤트를 만들지 않는다. 개인 예정 체류 120~240분과 운행 완료, 계획 진입 10,350명과 실제 진입/미진입을 구분한다.

예약 영역이며 실행 코드·서버는 없다. 현재 프로토타입에는 백엔드가 필요하지 않다.

실제 개발 때는 기존 Python 시뮬레이션을 재사용할 수 있는지 검토한 다음 라우터, 추천·집계 서비스, 저장소 계층, 입력 검증, 인증·권한을 구분한다. 기존 서버와 별도 서비스를 둘지 먼저 결정하고 중복 엔진을 만들지 않는다. 외부 API 키·DB 자격 증명은 프런트엔드에 넣지 않는다.
