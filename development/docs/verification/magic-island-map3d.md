# 매직아일랜드 3D 지도·넓은 보행 공간 검증

기준일: 2026-11-11. 체크리스트 2번의 현재 3D 지도·공간 정의를 검증했다. 변경은 로컬 `main`의 미커밋 상태다. 기존 팀 자료와 아쿠아리움 코드는 보존했다. 시뮬레이션 엔진은 후속 범위다.

현재 대기줄 곡선·수용량·시설 이동·화면 표시·새로고침 결과는 [2026-11-13 최신 검증](queue-capacity-and-reload.md)을 따른다. 광장 경로와 겹친 바닥 제거는 [광장 표시 검증](queue-and-open-plaza.md)을 참고한다. 아래 거리 표는 연결 그래프의 참고 수치이며 현재 화면의 광장 경로 거리와 구분한다.

## 반영한 요구

- 안내도 4쪽을 2400px로 다시 렌더링해 성 정면과 앞 광장·다리가 같은 사선 축으로 이어지는 것을 확인했다. 34개 꼭짓점으로 주 섬·남쪽 메이플 돌출부·다리 양옆 수면 홈을 구성하고 시설 좌표도 이 윤곽에 맞춰 배치했다. 성 정면을 회전해 성 정문·광장·다리를 같은 직선 축에 맞췄다. 원본 PDF 이미지는 저장소에 포함하지 않았다.
- 자이로드롭은 탑·곤돌라, 자이로스윙은 지지대·진자, 아트란티스는 물길·고가 코스, 자이로스핀은 디스크·U자 레일, 혜성특급은 열차·굽은 코스, 아르카나라이드는 소형 차량·순환 레일로 구분한다. 운행 중인 실제 상태를 의미하지 않는 정적 모형이다.
- 모든 시설은 `level: 0`이며 혜성특급도 지상 열차·굽은 코스로 표시한다. 표시용 공간 추상화이며 실제 시설 층의 실측 재현이 아니다.
- 섬 내부 대부분을 넓은 포장 보행 광장으로 정의했다. 시설·성·건물·식재·대기·하차 예약 구획을 제외하고 이동 가능하다. 성 정면 축과 시설 입출구를 비우면서 시설 사이·성 주변·메이플 구역에 11개 작은 식재 구획을 두었다. 나무도 해당 구획 안에만 배치한다.
- 관리자 앱 통합·영상·추천 등 미정 사항은 이번 작업에서 결정하거나 구현하지 않았다.

## 좌표·보행 공간 검사

[map.json](../../lotteworld/configs/map.json)이 평면 미터 좌표와 구획의 원본이다. JSON의 두 번째 평면 좌표를 3D의 z로 옮기고 y를 높이로 사용한다. 실제 위치·크기·높이·코스를 실측한 지도는 아니다.

[map_geometry.py](../../lotteworld/lotteworld_sim/map_geometry.py)의 `public_walkable`은 섬 윤곽에서 예약 구획을 제외하고 개인 반경까지 반영한다. 섬 밖에서는 다리의 유효 직사각형 안만 허용한다. 기존 녹지 위치의 광장이 실제 보행 가능하고, 다리부터 해당 광장까지 연결되는지 검사했다. 바다·시설·줄·식재 구획을 이동 가능으로 잘못 허용하지 않는지도 확인했다.

5m 간격의 섬 내부 표본 2,549개 중 1,846개(약 72.4%)가 반경 0 기준 일반 보행 공간이다. 이는 현재 가상 공간의 표본 검사이며 현장 포장 면적 비율의 실측치가 아니다. 대기·하차 영역은 별도 예약 공간이므로 이 일반 보행 비율에서 제외한다. 2m 격자에서는 다리에서 넓은 광장까지의 접근 연결을 확인했다.

참조 연결 그래프는 노드 37개·양방향 연결 37개다. 다리 폭 12m, 정면 광장 표시 폭 20m, 주 동선 8m, 입구 지선 5m, 퇴장 지선 3m다. 나머지 포장 광장의 보행 폭을 이 값으로 제한하지 않는다. 다리에서 각 입출구까지 연결된 경로와 거리를 검사했다.

위 표는 그래프 내 최단 경유 거리이며 현재 화면은 넓은 포장 면을 탐색한 별도 경로·거리를 표시한다. 실제 보행 엔진은 후속 단계에서 넓은 포장 영역과 장애물을 사용해야 한다. 대기 외곽 24×12m와 하차 합류 외곽 8×6m는 자리 정원이 아닌 공간 예약이다.

## 실제 브라우저 확인

- 1600×1100, 1024×900, 390×844에서 실제 WebGL 장면·6개 모형과 이름표·시설 목록을 확인했다. 회전한 성과 시설 모형의 x/z 바운딩 박스가 설정의 점유 구획 안에 있고 지상에 표시되는지 검사했다. 성 정문의 실제 장면 좌표와 다리 시작·끝의 공선성, 보행로 메시의 중심·폭도 설정과 대조했다.
- 시설 선택 시 접근·복귀 경로의 시작·끝과 미터 길이 합, 3D 탑 모형을 좌표로 클릭하는 Raycaster 동작, 키보드 목록 선택을 확인했다.
- 왼쪽 드래그 회전, 오른쪽 드래그 이동, 휠·버튼 확대·축소, 위에서 보기, 전체 시점 복귀, 배경 가림 줄이기와 복원, 선택 시설 확대를 실제 입력으로 검사했다. 모바일 크기에서는 터치 회전과 두 손가락 확대도 검사했다.
- 전체 보기·위에서 보기·시설 확대 화면을 직접 확인했다. 혜성특급 지상 표시, 작은 식재 구획, 넓은 포장 광장, 성·탑·진자·물길·레일의 구분을 확인했다. 전체 화면 캡처 과정이나 화면 크기 변경이 선택 시설 확대를 초기화하던 문제와 겹친 지면의 깜빡임도 수정했다.
- 가로 넘침·JavaScript 오류·실패한 HTTP 자원·외부 네트워크 자원 요청이 없었다. Three.js·OrbitControls는 [로컬 라이선스 사본](../../lotteworld/web/vendor/three/LICENSE)으로 제공한다.
- 캡처는 무시되는 `lotteworld/output/map3d-verification/`에 남긴다. 재실행 스크립트는 [verify_map3d.cjs](../../lotteworld/tests/verify_map3d.cjs)이며 별도 주소가 없으면 임시 포트의 최신 검증 서버를 시작하고 종료한다. 기존 서버의 오래된 메타데이터가 검사에 섞이지 않게 했다.

## 현재 상태와 남은 범위

체크리스트 2번의 3D 지도·시설 표시·넓은 보행 공간 정의를 완료했다. `status: map_ready`, `map_ready: true`, `map_view: guide-map-3d`, `runnable: false`다. 실제 시간별 도착·개인 체류, 사람의 충돌 회피·밀도에 따른 이동, 대기 자리·운행·재생은 3번 이후 범위이며 이 검사로 완료했다고 주장하지 않는다. 현재 개발 서버는 저장 후 새로고침으로 변경을 반영하며 Python 변경은 자동 재시작한다. 커밋·푸시는 수행하지 않았다.

## 2026-11-18 자이로스윙 좌석 기울기

원판과 좌석을 하나의 곤돌라 그룹에 배치해 동일한 기울기를 적용했다. 좌석의 바닥이 원판 윗면에 닿도록 로컬 높이를 맞춰 원판만 기울고 좌석이 수평으로 남던 표시를 수정했다. 시설 배치와 정적 모형 상태는 유지한다.

자이로스핀도 원판·중앙 장식·좌석을 같은 회전 그룹으로 묶었다. 원판과 좌석에 같은 기울기를 적용하고 좌석 바닥의 로컬 높이를 원판 윗면에 맞췄다. U자 레일과 지지대는 기존 위치를 유지한다.

자이로스윙은 우측으로 흔들려 올라간 정적 자세로 표시한다. 진자 길이 23m를 유지하며 중심을 오른쪽 8.16m 이동한 (232.16, 약 8.496, 42)에 두고, 원판·좌석을 진자 각도 약 20.8도에 맞춰 함께 기울였다. 전후 지지대의 바닥 간격을 시설 구획 안에서 넓혀 우측 자세에서도 기둥과 겹치지 않게 했다. 원판·좌석을 감싸는 반경 7.5m 구와 지지 기둥 표면 사이의 보수적 최소 여유는 약 1.47m다. 중앙 정지 자세로 표현하지 않는다.

## 2026-11-18 성 뒤 배경 건물 연결

기존 두 건물 구획 [123,50,18,25]·[147,50,24,26]의 위치와 크기를 유지하고 빈 틈 [141,50,6,25]을 같은 벽·지붕 높이로 채웠다. 표시 모형은 하나의 배경 건물 그룹으로 묶었고 연결부도 보행 장애물로 반영했다.

## 2026-11-18 혜성특급 열차와 레일 정렬

열차의 고정 좌표 배치를 제거하고 실제 레일 메시가 사용하는 곡선에서 차량 위치와 접선 방향을 구한다. 세 차량을 곡선의 호 길이 간격으로 배치해 위에서 봤을 때 각 차량 중심이 레일 위에 놓이도록 했다. 좌석 장식도 각 차량과 함께 이동·회전한다.

연결 건물의 최종 외곽은 [123,50,48,26]으로 통합했다. 기존 전체 외곽 위치를 기준으로 폭 48m·깊이 26m·전체 높이 8m(벽 6m와 지붕 2m)의 단차 없는 직육면체로 맞췄으며 보행 장애물도 같은 외곽 하나로 판정한다. 모두 가상 모형 치수다.

## 2026-11-18 매직캐슬 깃발 부착 방향

지붕 깃발을 수평 삼각 판에서 세로 천 모양으로 교체했다. 깃발의 왼쪽 가장자리 전체를 깃대에 고정하고 바깥쪽에만 작은 굴곡을 적용했다. 양면 재질로 성 정면과 반대쪽에서도 천이 보이게 하며 기존 깃대·성 위치는 유지한다.
