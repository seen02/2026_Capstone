# MAREA 화면 다듬기 / 시안 02

2026-11-11 현재 범위: 이 문서는 2026-11-06 아쿠아리움 정적 시안의 완료 기록으로 보존한다. 매직아일랜드 개발 기준은 [개발 명세](../../../docs/design.md)이며 아래 기존 검증 결과는 새 지도·10:00–19:00 유입·120–240분 체류를 검증한 결과가 아니다. 이 기록의 외부 방법 출처와 기존 화면 설명은 유지한다.

2026-11-06. 기존 관람객 웹과 운영자 대시보드에 Unslop의 polish 모드를 적용했다. 브랜드·색 방향·해파리 일러스트·기능·섹션 순서는 유지했다. 실제 API와 DB는 추가하지 않았다.

## 점검에서 발견한 사항

- 공통 미리보기 바: 넓게 자간을 벌린 작은 영문 대문자와 비실시간 상태 점.
- 관람객 첫 화면: 제품 역할보다 분위기를 설명하는 제목, 9–11px 메타, 큰 제목의 과도한 굵기·음수 자간.
- 관람객 섹션 제목: `YOUR NEXT DISCOVERY` 등 의미가 중복되는 영문 장식 라벨.
- 추천 카드: 추천 근거가 약한 감성 문구와 배지 안의 장식 아이콘.
- 전시 카드: 내용보다 장식이 앞서는 확대·회전 호버.
- 관리자 지표: 인원 수치와 무관한 미니 막대, 정원 진행 막대, 구역 문자 띠, 장치 점 등 네 종류의 보조 장식이 경쟁.
- 관리자 본문: 초록빛 배경과 여러 텍스트색, 8–11px 메타로 정보 위계가 약함.
- 관리자 탐색: 230px 사이드바와 일정하지 않은 행 높이·간격.
- 지도: SVG를 이미지로 묶어 내부 선택 항목의 접근성 의미가 사라짐. 휴대폰에서는 인원·상태를 한 줄로 축소해 표시.
- 공통: 카드 간격·안쪽 여백·버튼 반경이 임의의 값으로 흩어짐. 숫자 폭도 명시하지 않음.

## 다섯 줄 방향

- 제품: 관람객의 경로 선택과 운영자의 혼잡 판단을 돕는 아쿠아리움 웹.
- 성격: 차분함, 명료함, 여유.
- 세계: 전시 안내도와 관제실.
- 강조 장면: 관람객은 해파리 비주얼, 운영자는 지도와 인원 추이.
- 공통 디테일: 지도와 추천 카드에 이어지는 관람 경로선.

## 9개 패스의 변경 내용

| 순서 | 적용 내용 |
|---|---|
| 1 간격 | 바깥·카드·섹션 여백을 4px 단위로 정돈. 카드 안은 주로 24px, 관련 항목 간격은 8–16px. 운영 메뉴는 높이 36px·간격 4px로 통일. |
| 2 색 | 브랜드 청록은 유지. 관리자 바탕을 중립색 `#F7F8F8`로 변경하고 문자색을 본문·보조·메타 3역할로 정리. 미리보기 바도 밝은 중립색으로 낮춤. |
| 3 아이콘 | 기존 선 아이콘 체계를 18px·획 1.5로 통일. 지표 제목과 추천 라벨의 불필요한 아이콘 제거. 탐색 메뉴는 같은 박스·간격 사용. |
| 4 문구 | 관람객 제목을 ‘좋아하는 전시부터, 나만의 관람길’로 변경. 추천 이유에 기존 데이터의 ‘해파리 대기 12분’을 명시. 관리자 제목은 ‘아쿠아리움 운영 현황’. 장식 영문 라벨을 문맥에 맞는 한국어로 교체. |
| 5 글꼴 | 기존 시스템 글꼴 유지. 대부분 400·500, 브랜드만 600. 메타는 기본 12px, 본문 13–16px. 작은 글씨 음수 자간 제거, 수치에는 tabular-nums 적용. |
| 6 배치 | 기존 섹션 순서는 유지. 관람객 첫 화면의 텍스트·비주얼을 수직 중앙에 맞춤. 관리자 사이드바 240px, 콘텐츠는 가변 폭. 휴대폰에 기존 운영 메뉴의 탐색 경로를 노출. |
| 7 세부 | 지표 카드를 경계선으로 구분한 한 줄 요약으로 정리. 막대·문자 띠 등 보조 장식 제거. 차트는 한 계열 선과 옅은 면, 축 라벨은 HTML로 표시해 축소 시 읽기 유지. 오늘/어제 선택 상태와 구역 선택 후 키보드 포커스 유지. |
| 8 시각물 | 기존 해파리 SVG와 전시 실루엣 유지. 생성 이미지·새 장식은 추가하지 않음. 지도 역할을 group으로 바꾸고 구역별 인원·상태를 접근성 이름으로 제공. 모바일에서는 인원 중복을 줄이고 상태 문구를 키움. |
| 9 움직임 | 버튼의 위로 이동과 전시 그림 확대·회전 제거. 호버는 색·표면 변화, 토스트는 짧은 이동·투명도만 사용. 모션 감소 설정은 유지. |

## 확인 범위

JS 파일 5개의 구문 검사와 Git 공백 검사를 통과했다. 브라우저에서 관람 설정·추천 카드 이동·전시 상세·운영자 구역 선택·날짜 비교·안내판 모달을 확인했다. 기본 데스크톱과 390px 모바일 화면을 시각 확인했고, 390px·1024px 두 화면에서 가로 넘침이 없음을 DOM 치수로 확인했다. 관리자 메타 글씨는 12px 이상, 구역 선택 버튼은 모바일 13px로 확인했다. 콘솔 오류는 없었다. 추천 경로선도 F 공연 구역의 문자를 가로지르지 않도록 통로로 옮겼다. 정식 접근성 인증이나 실제 기기 전체 검증을 뜻하지 않는다.

점검과 변경 전후 확인을 포함해 화면별 시각 검토는 최대 3회로 제한한다. 촬영 이미지와 스토리 영상은 배포 파일에 포함하지 않는다.

## 남겨둔 범위

해파리 SVG의 빛 표현은 기존 전시 비주얼 자체이므로 유지했다. 지도는 단순한 가상 도식이고 인원 추이 역시 기존 가상 시계열이다. 추천 시간·운영 지표·장치 상태는 검토용 데이터로 유지하며 실제 관측·추천 성능을 주장하지 않는다. 생성 이미지를 요청하거나 사용하지 않았으므로 이미지 프롬프트는 없다.
