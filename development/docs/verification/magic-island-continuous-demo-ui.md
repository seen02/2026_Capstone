# 매직아일랜드 연속 시연 화면 검증

## 실행과 표시 기준

- 2026-11-19에 기본 설정인 배경 방문객 240명, 내부 배속 6배와 여섯 시설을 사용했다. 마커는 `/api/state.background.visitors`의 좌표에서 갱신하고 대기열을 보행자와 색으로 구분한다. 탑승 인원은 `rides.riding_people`, 대기 인원은 자리에 도착한 `queues.queued_count`를 표시한다. 차량의 승강장·코스 구간은 시설 상세에서 조회한다.
- 전체 지도는 약 0.4초, 사용자 웹은 약 2초 간격으로 상태를 조회한다. 두 웹은 같은 실행과 지도 해시를 기준으로 QR 위치·상태·경로를 표시한다. 모의 추천 경로는 선호 저장 시의 미리보기이며 현재 QR 캐릭터는 초기 위치에 머문다.

## 확인한 항목

| 검증 | 결과 |
| --- | --- |
| `python -m unittest discover -s tests` | 60개 통과. 하차 후 분산 보행, 광장과 다리의 보행 경로, 대기·탑승 집계, QR 세션 격리와 만석 상태의 탑승 순서를 확인했다. |
| `node tests/verify_map3d.cjs` | Chrome 1920×1080·1024×900·390×844에서 방문객 사람 모형, 인원 보존식, 시설 지표와 지도 조작을 확인했다. 지도 해시 불일치 시 운영 표시를 숨기고 정상 응답에서 복구했다. |
| `node tests/verify_user_entry.cjs` | Chrome 320px·390px 모바일 화면에서 터치 드래그와 선호 저장·복구를 확인했다. 혜성특급 수락 후 두 지도에서 같은 캐릭터의 대기·탑승·하차를 확인했다. 차량 번호와 출구 좌표가 일치했고 모바일 카메라는 보행 중인 캐릭터를 따라갔다. |
| `node tests/live-state.test.mjs`, `node tests/route.test.mjs`, `node tests/navigation.test.mjs`, `python -m lotteworld_sim.server --validate-only` | 실제 경유점의 보간, 갱신 지연 후 복구, 경로와 대기열 설정을 검증했다. |

QR 이용 검사는 수락 재시도와 동시 호출, 다른 쿠키의 수락 차단, 만료 추천 갱신, 대기열과 차량 정원 공유, 출구 도착을 포함한다. 자리와 좌석을 하나로 제한한 검사에서 기존 배경 대기객과 두 QR 캐릭터가 도착 순서대로 탑승했다. 기본 지도에서 초기 배치 102곳과 추천 대상 세 곳의 조합 모두 보행 경로 검사를 통과했다. 실물 휴대폰, 2시간 현장 부하, 수락 보상과 다음 추천은 후속 항목이다. [체크리스트](../implementation-checklist.md)

혜성특급 하차 분산 검사에서는 두 방문객이 빨간 출구를 순서대로 통과한 뒤 출구에서 10m 이내의 각 분산 지점부터 자이로드롭과 자이로스핀으로 다른 방향으로 걸어갔다. 두 경로의 공공 보행 가능 여부를 확인했다.
